    图库管理与分析明细

    该选项只影响之后发起的建库或刷新；不会自动重跑旧图库。原图裁脸提高已检测人脸的识别细节，不会补出检测器完全漏掉的人脸。

    新登记的来源显示「未建库」，点「开始建库」会一次完成扫描、搜索投影与语义索引， 再在后台继续缩略图、拍摄时间、地点与人脸/文字识别；语义索引进度由图库记录推导， 完整覆盖后才会显示「✓ 可以语义搜索」。建库完成后日常点「快速刷新此来源」即可， 它只处理变化。「刷新图库」对全部来源做同样的增量刷新；「完整校验扫描」仍会完整 校验每个位置的内容（次要维护入口）。「删除来源」只移除 PhotoSearch 中的记录， 不会删除、移动或修改文件夹中的照片。

    新增来源

    把照片目录的完整路径粘贴到下面的输入框。本页面不会枚举本机文件系统， 只有你亲手填写的路径会提交给本机服务。

    浏览图片

    “加入时间”是这张图片进入本机图库的时间，来自图库记录，不是 EXIF 拍摄时间。 「拍摄时间」只来自文件自身声明的时间（EXIF 原始/数字化时间）；文件系统修改时间 与 EXIF 根时间一律显示为「文件时间」，不参与拍摄时间范围筛选，也绝不被伪装成拍摄时间。

    拍摄时间范围是左闭右开：包含起始时刻，不包含结束时刻。留空表示该端不限。 只写日期时按当天 00:00:00.000 处理；带时区后缀（Z 或 ±HH:MM） 会被服务端明确拒绝，因为拍摄时间没有唯一时区。
