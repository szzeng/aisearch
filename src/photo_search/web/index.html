    建库选项与来源说明

    该选项只影响之后发起的建库或刷新，不会自动重跑旧图库。原图裁脸提高已检测人脸的识别细节，不会补出检测器完全漏掉的人脸。

    新登记的来源显示「未建库」；点「开始建库」会一次完成扫描、搜索投影与语义索引，再在后台继续缩略图、拍摄时间、地点与人脸/文字识别。日常点击「同步变化」只处理新增、删除、移动或改写的文件。完整校验扫描与删除来源位于单个图库的更多操作中；删除来源只移除 Photo Search 中的记录，不会删除、移动或修改文件夹中的照片。

          时间字段说明
          
    
            “加入时间”是照片进入本机图库的时间，来自图库记录；“拍摄时间”只来自文件自身声明的时间（EXIF 原始/数字化时间）。
            文件系统修改时间与 EXIF 根时间显示为“文件时间”，不参与拍摄时间范围筛选。
          
    
        
    
        
    
          
          
          
    
          
          
          
          
          
          
          
          
    
        
    
        
    
          
          
        
    
        
    
          
          
        
    
        
    
          拍摄时间范围是左闭右开：包含起始时刻，不包含结束时刻。留空表示该端不限。
          只写日期时按当天 00:00:00.000 处理；带时区后缀（Z 或 ±HH:MM）
          会被服务端明确拒绝，因为拍摄时间没有唯一时区。
        
    
        
    
        
    
          时间轴使用独立的年月定位与时间分组；列表视图中的排序和拍摄日期范围不会沿用。图库筛选会保留。
