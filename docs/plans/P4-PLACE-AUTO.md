# P4-PLACE-AUTO — 个人相册：GPS 自动地点、地名搜索与照片浏览

日期：2026-10-02，个人使用简化版。状态：**方案已收敛 / 未实现**。
唯一执行卡：[P4-PLACE-AUTO-A](../tasks/P4-PLACE-AUTO-A.md)。核对记录：[设计报告](../reports/P4-PLACE-AUTO-design.md)。

## 1. 交付目标

> 带 GPS 的照片不用逐张确认，就能按附近城市整理。地点页有封面和数量，点开能看照片。
> 输入城市、省份或国家名称可以找到这些照片；整理错了能改，改过的不会被后台改回去。

首版保留用户选择的**城市＋国家/省份**。目标是本机源码运行、方便个人日常使用。
本轮只优化任务安排，未执行产品实现或真实图库处理。

## 2. 只用一张功能卡

此前“3张主卡＋约5张审查卡”被本简化版取代。统一在 A 卡完成：

1. 短设计：在同一报告确定浏览集合、GPS选择、省份资料和最小API。
2. 前后端实现：自动地点查询、地名入口、地点卡片/照片网格、已有照片补齐。
3. 简单验证：小合成图库的定向测试＋一次真实浏览器闭环＋静态检查。
4. 达到本机可用后结束，进入个人试用；后续只按实际问题修复。

用户明确要求“个人使用，简单功能与测试即可”。因此本卡不单独拆契约冻结/工程主审/Sol终审，
不要求全量B/D套件、30万基准、准确率研究、复杂故障全集或exe构建。此例外只适用于这张个人试用卡；
原图、人工控制、身份和结果一致性检查保留，其他既有待审任务不追认PASS。

## 3. 功能与实现取舍

| 功能 | 本次做法 |
|---|---|
| GPS自动整理 | 复用已有GPS事实和离线城市候选，取一处主城市，显示“GPS附近城市” |
| 人工优先 | 指定地点使用人工结果；人工取消阻止自动分组；恢复自动保留排除，复用已有操作 |
| 地点首页 | 有照片的地点卡片：名称、上级文字、封面、完整去重数量；原管理入口保留 |
| 地点相册 | 点击卡片看照片，复用缩略图/详情/分页；数量和列表同一集合，不受语义Top5000限制 |
| 地名搜索 | 主搜索框输入地名显示地点入口及照片预览，点击查看全部；地点页也可按名称/别名查找 |
| 国家/省份 | 国家复用现有祖先；省份用城市的轻量只读附加索引，不新增省级人工状态机或改旧父级 |
| 已有照片 | 有效GPS/候选直接参与浏览；缺GPS/解析的复用现有任务补齐，只处理缺项 |

新增相册查询与原有人工place_ids/place_state、place_text分开，旧接口/FTS人工口径保持。
第一版通过明确的地点入口或地点模式查全量照片，不改普通自然语言混合排序、不增加GPS FTS世代。
用户无需手工填写ID。人工地点与自动城市使用一套浏览集合，避免计数、搜索入口和网格各自判断。

省份优先用地名包可选INDEX文件携带城市外部ID→省级ID/名称/别名，复用包文件校验。
旧包缺索引仍能浏览城市/国家；新准备的小包验证省份。不能原地改已激活包或伪造省份。
省份是参考城市的附加资料，不是GPS行政边界判定；直辖市等避免重复名称，缺资料允许缺级并说明。
需要公开映射时优先复用已有原始数据及同快照的小文件，不重下载全球地名/模型。

## 4. 简单规则与必要边界

- 一个资产只有一处主浏览地点；多个文件位置只算一张。国家/省份汇总主城市，不把三个候选都算入。
- 自动只读当前内容/GPS/活动包的结果与当前人工控制。最近城市采用**50km以内**的个人整理初值；
  这是便利用的距离上限，不是行政包含或准确率保证。等距、太远、无效GPS、未知基准、缺包不自动分组。
- ASSUMED_WGS84可作有来源标记的推算依据；缺精度不编造精度。被排除的首选不自动顺延到更远城市。
- 人工改/取消后，旧自动地点立即退出浏览集合；机器建议可留存，不能伪造人工确认或操作。
- 原文件离线仍可显示已存缩略图并提示；隐藏/移除、来源筛选与现有资产浏览规则一致。
- 翻页绑定影响浏览集合的现有revision及省份索引版本；变化时重载，计数/封面/照片不混版。
- 不写原图GPS、不改资产身份或人工表语义、不重算向量/人脸/OCR，坐标不进入普通日志/URL。

50km是本次个人整理的建议默认值，做边界测试和小样本观察即可，不另开阈值研究。
真实试用出现误分组时，优先人工改正或定点调整参数；所有机器结果继续标“附近城市”。

## 5. 最小验收与停止点

用约20～30张合成照片/资产、一个小地名包验证：

1. GPS-only照片→城市卡片/网格/地名入口；省份/国家有映射时可搜索并汇总。
2. 人工改/取消→数量和照片立即变化，重启/重复补齐不改回；恢复自动保留排除。
3. 同内容双位置、隐藏/离线、小分页→去重准确，数量等于全部分页集合。
4. 无/坏GPS、未知基准、缺包、50km边界/等距→不崩溃、不乱分组，人工入口仍可用。
5. 已有GPS补齐、重复执行/重启→无重复，不触发向量/人脸/OCR重建。
6. 真实浏览器一次“搜地名→地点卡片→照片网格→详情→纠错→重载复核”。

定向pytest保存JUnit，Ruff/diff-check通过，真实浏览器有记录后可写
**PASS — 本机个人地点相册与小样本验证**；不代表30万性能、精确行政区、发行或全量质量通过。
完成后不自动生成B/C、审查/优化/发行卡。地图、街道/商家/景点识别、轨迹、云反查、视觉推测和复杂省级编辑后置。
真实个人库补齐仍需明确来源/范围授权，此次优化方案不包含该授权。
