日期：2026-10-09。状态：**范围优化完成 / 审查尚未执行**。直接依据：用户要求“个人相册，测试简单些，把前面待审核的任务都优化”。本修订只改审查入口、验证要求及交接，不修改产品、测试、依赖、历史ADR或已有审查报告，不将待审任务自动标PASS。

## 1. 当前规则

本文件及所列卡首的个人验收范围，替代这些任务过去重复的测试/多阶段审查安排。V3.1修订12与AGENTS已同步此限定例外。历史全量失败及未测项照实保留，不要求先修全仓93项；全量基线方案保持DEFERRED。

1. **先读证据，不默认重跑。** 每项必要行为先指向已有JUnit/JSON/截图/审查结论，核对对应代码和后续改动。代码、测试输入、配置、依赖或相关运行环境有变化，只补变化影响的用例。证据不可读、不能确认对应版本或存在矛盾时补最小验证；报告中的一句“通过”不能替代不可核对的关键证据。
2. **同一保护只检查一次。** 一条共享身份/成员/人工保护链已有独立结论时，后续任务只列引用及新增差异；共同API/UI基础流程只做一次，多个任务复用该结果。不把相关任务的通过自动推广到未覆盖分支。
3. **保留完整新增面，缩减重复执行。** 首次独立工程审查仍查看本组尚未审过的全部改动文件和直接调用链；无需全仓阅读。人工关系、身份、迁移、激活、恢复的拒绝/零写入/回滚必须有直接证据。典型正常路径加关键拒绝/撤销即可，不按用例总数考核或遍历异常组合。
4. **只补基础测试。** 默认小型合成图库（约6～20张；实际分页边界可复用61张、5005条轻量记录），fake encoder与离线小包；不重新建30万夹具、跑全量、模型质量/GPU速度矩阵、构建exe或重扫照片。已有真实模型/CPU-GPU证据核对后复用；不可用时记录环境/效果未验证，不用fake证明真实推理。
5. **一次审查收口。** 没有新契约决定或高风险未决问题时，独立DS-H完成本组工程审查即可，记录SOL_NOT_REQUIRED。已正式冻结的规则不再次冻结。需要正式改变冻结契约、尚有身份/人工数据安全矛盾，或下文点名的模型维护选择适用性未决时，才保留Sol聚焦短裁决；只读未决项/关键反例，不重走全diff。
6. **小修只补直接回归。** 已知旧fixture/接口断言不能证明新需求错误；先核对授权与ADR，再修最小fixture/oracle或报告产品缺陷。关键流程的失败必须关闭，不能deselect/skip/xfail掩盖。无关全量失败保留在后置清单，不在本组批量修复。
7. **范围如实标注。** ENGINEERING REVIEW PASS与个人基础交互通过分别记录。个人任务必须完成其卡面剩余基础项才可标“PASS — 个人相册基础功能与小样本验证”；不等于真实图库质量、全仓、容量、正式冻结或发行通过。暂未做到的浏览器/环境项只标待验。

## 4. 实际验证约定

审核先列“必要行为 → 已有证据 → 当前差异 → 是否补测”四列表。没有补测需求可不运行pytest；有缺口用现有测试节点/文件，避免新建大量镜像测试。基础前端闭环能由已有合成真实浏览器覆盖就复用；纯DOM只能证明其自动化范围，不能标实测浏览器。

需要补测时（具体节点由各卡给出）：

```powershell
$env:UV_CACHE_DIR = Join-Path (Get-Location) '.uv-cache'
$env:PYTHONPATH = (Get-Location).Path
# uv run --no-sync pytest -q <卡面直接受影响节点> --basetemp=.pytest-tmp/<本组新目录> --junitxml=test-results/<本组补测>.xml
# 仅实际修改的Python/JS跑Ruff、Node；依赖相关变化再uv lock --check。
git diff --check
```

每条命令即时记退出码；JUnit统计与实际执行相符，collect-only不算通过。项目内缓存/临时数据；不改ACL，不清理别的会话目录。所有卡禁读写私人照片/PhotoSearchData，禁下载模型/PBF，禁重启用户实际服务、扫描/建库、提交/推送；已有用户授权的历史操作只引用报告，不继承成新授权。

补测发现产品高风险缺陷时记录精确反例，只修该边界与直接回归，不因本例外取消人工保护或冻结契约。真正新增协议/迁移/运行库/正式发行工作另按原策略立卡；本例外覆盖现存待审任务的个人收口，不预授权后续全局修改。
