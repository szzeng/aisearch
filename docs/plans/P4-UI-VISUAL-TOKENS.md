## 字体、间距、控件

- 用系统字体 `system-ui, -apple-system, "Microsoft YaHei", sans-serif`，不下载字体；演示正文约14px、主标题27px、区块标题18px、辅助信息12px，是**参考层级**而非强制全站根字号。支持浏览器自定义字号和缩放。
- 常用间距8/12/16/24px；按钮、输入、卡片、chip 的边框/圆角/阴影/hover/focus/disabled 沿用一套语义变量，错误和危险操作不能只靠颜色区分。
- 公共壳为照片/人物/地点主导航、地图/图库管理次级、页头唯一全局自然语言输入；人物/地点目录筛选不等同全局自然语言搜图。
- 页面专有选择器加稳定根作用域（例如 `body.search-page`），避免裸 `.panel/.grid/.chip` 改到其他页面；真实 DOM ID/请求/状态优先，不复制 demo 模拟数据。
- 系统 `prefers-color-scheme: dark`、窄屏、键盘操作和真实200%页面缩放均应可用；工具无法完成实测时写 PENDING，不能拿 DOM 检查当视觉通过。
