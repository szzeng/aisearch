## F1 当前落地选择（2026-10-13）

- `src/photo_search/web/styles.css` 已将上述亮/暗色值接入 `:root` 与 `prefers-color-scheme: dark`；另有独立 `--danger`、`--radius-sm`/`--radius-lg`、`--space-*`、`--shadow-soft` 与 `--font-ui`。根字号保持浏览器默认，正文未全局缩小。
- 公共外壳仍由 `body.app-shell` 管理；品牌符号由 `.app-brand::before` 构成，导航图标是显式 `<span class="nav-icon" aria-hidden="true">`，不混入链接可访问名称。`--tint` 提供选中/悬停底色，warning/error 保持独立语义色。
- `src/photo_search/web/search.css` 的所有规则均限定在 `body.search-page`；结果卡为 4:3 图片优先布局，chips/提示/空状态沿用真实结果字段。长篇条件说明进入原生 `details/summary`，表单、结果 ID 和加载更多节点保持原样。上传和覆盖率面板采用次级底色，不自动读取覆盖率。
- 当前只在内置浏览器约 374 CSS px 窄视口实看导航、空/有结果与筛选展开；和 demo 的 30 条假结果仅作观感参考，未复制演示数据。1440/640 指定视口、暗色、真实 200% 缩放、截图文件与完整对照仍 pending。

## 字体、间距、控件

- 用系统字体 `system-ui, -apple-system, "Microsoft YaHei", sans-serif`，不下载字体；演示正文约14px、主标题27px、区块标题18px、辅助信息12px，是**参考层级**而非强制全站根字号。支持浏览器自定义字号和缩放。
- 常用间距8/12/16/24px；按钮、输入、卡片、chip 的边框/圆角/阴影/hover/focus/disabled 沿用一套语义变量，错误和危险操作不能只靠颜色区分。
- 公共壳为照片/人物/地点主导航、地图/图库管理次级、页头唯一全局自然语言输入；人物/地点目录筛选不等同全局自然语言搜图。
- 页面专有选择器加稳定根作用域（例如 `body.search-page`），避免裸 `.panel/.grid/.chip` 改到其他页面；真实 DOM ID/请求/状态优先，不复制 demo 模拟数据。
- 系统 `prefers-color-scheme: dark`、窄屏、键盘操作和真实200%页面缩放均应可用；工具无法完成实测时写 PENDING，不能拿 DOM 检查当视觉通过。

## 精简视觉验收与控件选择

- 实施前对照 UI 2.0 Demo 和本卡目标布局；小型对齐、间距、颜色、文字修改可直接做，主要结构重排或迁移重要入口先明确目标布局，存在实质取舍时请用户确认。
- 修改后在 Codex 内置浏览器检查受影响页面：对齐、留白、间距、控件尺寸、文字换行/溢出、主次层级和一个典型窄窗口。明显偏差应局部修复后再看；代码测试通过不代表视觉通过，无法观察的项目记为 PENDING。检查范围随改动大小控制，不要求小修复做全站截图或安装额外浏览器工具。
- 高频且少量互斥选项可用分段按钮；来源、排序等较多或语义明确的选项保留原生下拉框；需比较说明的少量选项用单选；低频高级条件使用清楚、不过度嵌套的原生折叠区。选型须保留键盘操作、可见标签和当前值，不为统一外观而机械替换下拉框。
