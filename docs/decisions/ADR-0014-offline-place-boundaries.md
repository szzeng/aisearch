# ADR-0014：离线行政边界与景区叠加

2026-10-01，用户接受实现范围；实现者验证完成，独立工程审查待进行。取代 ADR-0005 中“仅人工结果有效”、目录类型和附近城市建议作为唯一自动能力的限制；其人工锁、幂等、补偿撤销、GPS 事实与隐私约束继续有效。

当前 schema 为 18。0017 已用于地理边界，0018 修复地点停用/恢复后的全文索引排队，并补排 schema 17 下可能残留的旧地名。ADR-0013 预留的 UpgradeRun 0017 编号因此失效；冻结 JSON 保留为 schema 16 上的历史设计证据，未来实现必须基于当前 schema 重新编号和复核，不能直接执行旧参考 DDL。

- 目录 API 使用 `place-geography.v2`：`country/province/city/district/attraction/custom`，允许缺级。旧 GPS、建议、操作历史协议保持 v1。migration 0017 原位保留 place_id、revision、父级、别名、外部引用、控制及历史；保留自增序列和禁止硬删除触发器。迁移前备份，重建表在事务内，提交前检查外键，失败回滚并恢复连接外键约束。
- 行政地区形成单父级树；景区是独立多边形叠加层，可以跨市、跨省、相互重叠，不强行挂到一个城市。照片可同时命中一个最具体行政地区及多个景区。父级集合通过祖先链展开并按 asset_id 去重；界面只显示当前层级、有照片的集合，可展开空目录或搜索全目录。
- Shapely STRtree 在 CPU 上做 GPS 点与 Polygon/MultiPolygon 包含查询。包含多边形边缘、排除空洞；多个互斥行政区域命中时只保留共同上级并标 `AMBIGUOUS`，没有共同上级则不归类。几何匹配不是测量精度保证，当前不按 GPS accuracy 构建不确定圆。明确 WGS84 和缺 datum 的 `ASSUMED_WGS84` 可匹配，后者在详情显示假定基准；未知/已知其他 CRS 不匹配，不静默转换。跨日期变更线的多边形须由供包方拆分。
- `boundary_packages/features/results/memberships` 保存版本、SHA-256、许可、覆盖、区划年份、WKB 和输入 lineage。一个行政 namespace 可激活，多份景区 namespace 可共存。外部稳定 ID 映射本地 place_id，不按名称合并；新包不得悄悄改变既有 ID 的类型或父级。保留用户改名。区划拆并须有新的外部 ID；跨数据源身份迁移仍需单独设计，当前拒绝第二行政 namespace。
- `effective_asset_places` 是唯一可查询的有效关系视图：人工指定优先；人工取消阻止所有自动结果；AUTO_ALLOWED 只读当前包、当前 GPS fact 和资产 revision 且未被本人/祖先排除的成员。自动任务不写人工控制行。恢复自动保留排除；显式指定可解除阻挡该目标的排除。取消和改派记录原自动成员，现有撤销恢复其控制与排除。
- 导入先完整验证，再原子切换包；旧包记录保留但退出有效视图。已有 GPS 分批恢复计算（每包每批最多 200），不读取原图、不加载视觉模型。提交重新校验活动包及输入；暂停与应用关闭可中止，重启按 lineage 补齐。包切换期间未重算照片暂时无自动归属，人工关系一直保留。有效关系变化同事务递增过滤版本、排队 FTS 和刷新派生投影，旧搜索会话失效。
- 新接口 `GET /places/browse`、`GET/POST /places/boundaries` 复用认证、CSRF、Origin/Host 防护。导入只接收有界 JSON（64 MB），来源仅允许 HTTP(S) 展示链接，运行时不请求外部服务。计算/导入离开 HTTP 事件循环；精确坐标不出现在集合、日志、URL 或向量库中。

实际数据：工具 `tools/places/prepare_boundaries.py` 固定 mapchina 源提交及 SHA-256，生成 3,269 个目录节点、2,901 个区县多边形；原始数据未给出区划年份，包含历史区县，界面持续提示，不能视为最新全国行政区划。许可 GPL-3.0，来源与修复数量在包内。另接入 OpenStreetMap relation 13164471 的杭州西湖风景名胜区范围（ODbL-1.0，署名 OpenStreetMap contributors）。准备时仅请求公开固定地名；正式运行全离线。数据文件位于应用数据目录，源代码中不带数据包。`rdata` 是可选准备工具依赖，运行应用只新增 Shapely。

未交付：全球/最新全国完整区划、全国景区库、地图瓦片、视觉猜地点、GPS 精度半径推断、行政跨数据源迁移。十万图地理查询性能和 Windows 冻结 GEOS 依赖尚未实测。验证证据及下一审查入口见 [任务记录](../tasks/place-geography.md)。
