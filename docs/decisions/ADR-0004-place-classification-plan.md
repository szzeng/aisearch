# ADR-0004 — 实际地点分类与 P2 前置规划

- 日期：2026-09-13。
- 状态：ACCEPTED FOR PLANNING；实现契约尚未冻结，功能未实现。
- 输入：用户要求在 P2-01 前详细规划地点分类并更新架构与策略，随后确认“实际地点：国家／城市／景点／自定义地点，支持 GPS 和手动归类”。
- 基线：`e42c544`，P1-06 已验收；开始时工作树干净，schema_version=1。
- ADR-0003 编号保留给既有 P2-01 通用协议；本记录使用 ADR-0004，后续地点实施契约由 P2-01A 写 ADR-0005。编号不表示实施顺序。

## 决策

1. 地点是拍摄所在地的独立业务维度，与文件位置、人物、场景标签分别建模；使用稳定 place_id。
2. GPS 原始事实、地名解析候选、人工有效归属分开保存。人工数据以 catalog.db 为权威，图文索引和地名数据包均不能覆盖它。
3. 首版提供地点层级、无 GPS 手动归类、指定／取消／恢复自动、批量操作／撤销，以及 GPS 附近城市建议。每资产最多一个有效最具体地点，祖先自动展开。
4. 首版 GeoNames 点数据只产生待确认建议。没有行政边界或用户规则证据，不把最近城市当作行政区包含关系，也不宣称自动识别准确景点。确认建议使用人工 assign 用例。
5. 同名地点不自动合并。地点“家”可没有坐标，城市／景点可以由用户手动创建；不要求真实图库目录先分类。
6. 延用人物人工知识保护原则，但不复用人物同名合并规则；地点控制以 asset_id 为单位，人物控制仍以 face_id 为单位。
7. GPS／地名处理在 CPU 上执行，无模型也必须有版本化 processor_id；不添加云端 API、地图服务、第二向量后端或常驻大模型。
8. 地点纯筛选读 SQLite；地点与语义组合使用权威候选约束和投影补查。人工更新递增 catalog_filter_revision，受影响分页会话过期。
9. 地名包版本独立于 SearchProfile；更新包不重算图文向量，不回滚人工地点。备份必须保护地点操作历史及脱离地名包仍可显示的名称／层级。
10. 沿用已验收静态前端建设地点页；Vue 等前端框架迁移后置为独立决策。保留原首版 HEIC 和拍摄时间目标，分别明确安排实现任务，不能将未实现的目标描述为已交付。

## 为什么现在加入

P2-01 尚未冻结，能及早避免三个返工点：ProcessorSpec 强制每种任务都有模型／向量字段；索引外壳把所有产物都当向量；搜索会话只绑定 profile 而忽略人工筛选变更。此时只更新规划和任务入口，不重做 P1。

完整不变量见 [主架构 §4.5](../../个人图片搜索系统_V3.0_开发主架构.md)，分阶段交付、成本和验收矩阵见 [路线图](../plans/P2-00-location-project-roadmap.md)。本 ADR 与主架构冲突时必须一并修订，不由实现者静默择一。

## 边界与代价

- 规划不修改 ADR-0001/0002、0001_initial.sql、生产代码、测试或依赖；实际迁移编号由实施时仓库顺序确定。
- 增加四个 P2 子任务：P2-01A、P2-03A、P2-03B、P2-03C。它们分别承担地点契约、数据/API、离线解析、界面；P2-08 统一恢复验收。
- 新的 CPU 开销来自 GPS 读取、地名包构建／查找、FTS／投影更新；没有地点专属 GPU 模型或 API 计费。实际包大小、构建速度与覆盖率待试验，不能给出未测工期或吞吐保证。
- 为低误归类选择“附近建议需确认”，自动覆盖率会低于直接最近点归类。需要自动行政区／景点能力时，先完成数据覆盖与边界算法专项任务，不隐式放宽准确性。
- 单最具体地点适合普通拍摄照片；拼图、多地点扫描文档不强行归多个拍摄地，可用标签／备注描述。
- 用户对功能范围的确认是需求证据，不表示用户逐项批准了数据库字段；DDL、状态枚举与错误码在 P2-01A 单独冻结与校验。

## 外部依据与尚未验证

2026-09-13 阅读 [GeoNames 官方导出说明](https://download.geonames.org/export/dump/readme.txt)：有城市点、国家／行政区引用及多语言名称，使用 CC BY 4.0；计划按选定快照构建本地包并保留归属说明。选点数据的方案不借用其边界数据保证行政包含关系。

EXIF 实现参考 [CIPA 标准入口](https://www.cipa.jp/e/std/std-sec.html)，实施时固定采用的版本并验证 GPSLatitude/Longitude、Ref、MapDatum 和误差字段。

本次没有下载地名包、运行 GPS 解码、验证中文别名覆盖、地图边界、最低配置性能或访问任何真实照片。外部资料证明数据格式／来源，不能代替项目集成验收。
