## 应保持的视觉目标

- 清爽灰白底、柔和青绿强调、短说明、照片优先；左侧导航固定，管理位于次级位置，窄窗口改为横排。
- 网格留白、照片尺寸、卡片圆角、标题和按钮层级参考图；实际尺寸随窗口自适应，不要求像素复制。
- 搜索页只有一个主输入框；其他页的全局搜索入口进入原搜索流程。A先完成入口，文字交接到C。
- 人物的浏览/整理层级、地点相册/地图切换、高级工具折叠、查看器大预览/信息面板清楚。
- 高亮只表达当前入口，暗色、键盘、错误和加载状态仍须按任务卡实现；图中未展示不等于可以省掉。

## 不能照搬的部分

示例图形用真实缩略图替换；姓名/地名/数量/状态用已有API事实替换。草图的解释文案、示意导航行为不是产品契约，不能加入虚构总数、自动确认、额外统计或新的写操作。

**业务与安全规则以现有契约及任务卡为准；画面布局与视觉层级以模拟图为参考。** 两者冲突时保留业务不变量，做最小布局适配，并在报告说明；不为了接近示意图更改核心接口。A阶段只实现外壳，不提前实现图中的B～F功能。

## 实现后如何对照

每张卡报告中列出实际查看过的参考图，并保存对应产品页面的合成数据截图；在接近窗口宽度下对照导航、主次动作、留白、照片占比与返回操作。只核对本卡改变的页面和状态，不为像素差异新建自动截图基准或重跑无关矩阵。重要视觉偏离写明原因，不能仅以静态测试通过代替画面观察。

## 现状盘点是备份参考

[逐页信息盘点](../plans/P4-UI-INFORMATION-CHECKLIST.md)记录现有能力，不要求119项全部显示、原样保留或全部画进模拟图。用户以前明确强调必须增加/保留的项目按该文档第0节的需求证据落实；其他信息可按方便和清新的目标精简、合并或折叠。此前本节“图中未画出的也须全部保留”的要求撤回。

示意“所有人物”不定义新混合查询；查看器“地点”不表示共享组件已有完整地点归属编辑器。界面取舍沿用零业务接口变更的范围。
