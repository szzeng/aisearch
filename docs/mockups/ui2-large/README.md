## 核心视觉与逻辑边界

1. 照片时间轴支持拍摄/入库依据、日/月/年粒度、年/月**筛选**与**直接跳转**（非同一动作）；从数据库 Keyset 有界分页、年月汇总按需、浏览器离屏缩略图/DOM 回收。
2. **已提取但无可靠拍摄日期**与**时间未就绪/规则版本不匹配**分别入口，桶内均按入库时间倒序；**没有手动补日期/文件名推断/AI猜日期功能**。
3. 纯条件搜索（年份、入库日期、人物、地点、合集、未知状态）走原权威 SQL；有真实内容词才需要 FTS/向量召回。语义 TopK 候选不能冒充全库匹配。
4. 人物/合集/地点照片接共用时间轴，整理中人脸组仍按任务工作流；地图聚合与视口成员真值不变。不得用前端单页排序替代服务端全相册时间排序。
5. **20万照片规模的毫秒数均为目标，尚未实测**。此目录图片不证明功能实现或性能验收；不得访问真实 PhotoSearchData。
