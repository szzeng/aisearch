## 2026-10-13 两项视觉修正说明（以任务卡与最新规范为准）

**搜索图需要在下一轮单独重绘**：当前 12/13/14-search SVG 的顶部“搜索照片、人、地点”与内容区搜索大表单**重复**，而部分图侧栏还有“搜索”一级导航。正确产品稿是**全站页头唯一全局搜索框、结果页相同位置复用、左侧移除重复搜索项但 /search 路由仍有效**。本次只优化任务卡和规则，不谎称已经修正 SVG 像素。
**人物/地点目录不是拍摄日期列表**：05-people/09-places 卡片默认按**有效照片数降序，同量最新照片入库时间降序**；缺拍摄日期的照片仍计入总数。06-person-album/07-person-collection/10-place-album 进入具体相册后才使用可信拍摄时间轴，并在**当前相册 scope**下提供“日期未知/待就绪”入口（切到入库时间时全数归入入库年月）。人物/地点目录不逐卡求年月/未知数，避免20万以上图库多卡 N+1 慢查询。

## 当前相册快捷搜索新增设计规则（2026-10-13）

人物相册标题处应有「搜索此相册」，人物合集标题处有「搜索此合集」，地点相册标题处有「搜索此地点」；点击后复用**页头唯一全局搜索输入框**并展示固定的「张三的照片 × / 家庭合集 × / 深圳市 · 广东省 ×」范围标签，而不是恢复相册正文的第二个检索输入框。输入“海边”只查该相册所有有效成员、包括拍摄时间未知的照片；不自动继承当前年份筛选。直接点击页头全局搜索默认全图库；人物目录「筛选人物」和地点目录「筛选地名」是局部名字筛选。

**注意**：本目录现有 SVG 是上一版，尚未绘制新增的范围快捷按钮/chip；新的确认版 PNG/HTML 如果在当前会话中生成但未上传到 GitHub，不要假装这里已有其文件。本次以 [规范§1.3](../../plans/P4-UI-TIMELINE-V2.md)、D/E/C/SEARCH-MAP 任务卡为执行权威。旧人物局部搜索功能必须在新端到端路径验收后才替换，地点未接通时不显示无效快捷按钮。

## 核心视觉与逻辑边界

1. 照片时间轴支持拍摄/入库依据、日/月/年粒度、年/月**筛选**与**直接跳转**（非同一动作）；从数据库 Keyset 有界分页、年月汇总按需、浏览器离屏缩略图/DOM 回收。
2. **已提取但无可靠拍摄日期**与**时间未就绪/规则版本不匹配**分别入口，桶内均按入库时间倒序；**没有手动补日期/文件名推断/AI猜日期功能**。
3. 纯条件搜索（年份、入库日期、人物、地点、合集、未知状态）走原权威 SQL；有真实内容词才需要 FTS/向量召回。语义 TopK 候选不能冒充全库匹配。
4. 人物/合集/地点照片接共用时间轴，整理中人脸组仍按任务工作流；地图聚合与视口成员真值不变。不得用前端单页排序替代服务端全相册时间排序。
5. **20万照片规模的毫秒数均为目标，尚未实测**。此目录图片不证明功能实现或性能验收；不得访问真实 PhotoSearchData。
