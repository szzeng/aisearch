## 执行注意

1. 实施 A、B、D、E、C、F 及两个新时间轴卡前，按本目录对应页面看最终布局，再对照当前仓库产品代码与原任务卡；已完成的人物管理/Esc/原图打开等能力不重造。
2. 拍摄时间与入库时间语义、日期依据的可靠性、日/月/年分组、年月筛选与直接定位、自动续页，以及返回浏览现场，均以 UI 2.0 规范为准。SVG 控件位置为视觉建议，不能替代真实 API 契约。
3. 人物待整理/人脸批量管理是任务流，不需要强加普通时间轴；地图点仍按 viewport 成员；搜索默认相关度，不将当前一页排序假称全结果时间轴。
4. 所有照片、人物、地名和数量均为**合成示意**。不访问用户真实图库。浏览器打开 index.html 可切换静态页面；生产功能需按各任务卡另行实现。
