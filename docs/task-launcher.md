# 下一任务自动生成规则

每完成一个开发任务后，不要等待用户手工填写下一任务模板。

请根据仓库当前实际状态自动生成下一任务的完整执行任务卡。

## 1. 读取顺序

首先读取轻量入口：

1. `AGENTS.md`
2. `docs/development-status.md`
3. 当前任务卡和当前任务的测试报告
4. 当前 Git 状态和最近提交
5. 与下一任务直接相关的已有实现、接口和测试

然后按需读取：

6. 开发执行策略中用于确定依赖、模型路由、升级条件和模板的相关章节（通常为第 2、6、7、8 节）
7. 主架构目录，以及与下一任务直接相关的章节

默认不读取两份 V3.0 文档全文。只有以下情况才全文读取：

* 首次进行架构对齐
* 当前或下一任务卡缺失，或与仓库真实状态冲突
* 任务需要作出跨模块架构、协议或数据语义决策
* 用户明确要求完整架构审查

进入新的子任务或阶段时，读取该阶段和任务直接相关的章节，不因阶段编号变化自动阅读全文。

不得仅根据聊天历史推断项目状态。

## 2. 确定下一任务

依据：

* `docs/development-status.md`
* 开发执行策略第 6 节任务依赖关系
* 当前真实 PASS / FAIL / BLOCKED 状态

确定唯一的下一任务。

如果一个计划任务适合拆成多个独立可验收子任务，应拆成：

`P?-??A`
`P?-??B`
`P?-??C`

但保持它们仍属于原计划任务，不擅自修改总体路线。

## 3. 自动选择执行模型

依据开发执行策略中的任务路由表和第 6 节指定模型。

例如：

* C0 → GPT-5.6 Luna
* C1 → GPT-5.6 Terra
* C2 → GPT-5.6 Sol
* DS-N / DS-L / DS-H → DeepSeek V4.1 Flash

同时写明 reasoning 档位。

不得因为当前模型是谁而擅自改变计划中的模型分配。

模型选择只是任务记录；如果当前客户端无法切换到指定模型，明确输出“需要用户在对应客户端启动此任务”，不得声称已经切换。

## 4. 自动选择模板

按照执行模型选择开发策略第 8 节模板：

* C1 / Terra → C1 集成与接手模板
* DS-N / DS-L / DS-H → DS-F 实现模板
* C2 / Sol → C2 高风险任务模板
* 模型之间发生失败接手时，同时读取上一任务的交接记录

不要把模板中的 `{...}` 占位符保留给用户填写。

必须根据当前仓库实际情况全部填充。

## 5. 自动填充的信息

生成任务卡前，必须从仓库中确定：

* 任务 ID
* 当前 Git 基线提交号
* 上一任务及状态
* 实际执行模型
* reasoning 档位
* 本任务用户场景
* 需要读取的架构章节
* 相关现有实现
* 允许修改的文件或目录
* 禁止修改的范围
* 本任务必须保持的数据/接口不变量
* 已存在的类型/API/迁移/协议
* 正常行为
* 异常行为
* 边界情况
* 验收命令
* 需要更新的测试报告
* 完成后应该进入的下一任务
* 什么失败条件需要升级到其他模型

不能确定的内容必须标记为“执行时先检查”，不能凭空编造文件、接口或命令。

## 6. 任务粒度

任务必须是一个可以独立验收的闭环。

禁止生成类似：

“完成整个 P0”
“实现完整搜索系统”
“完成所有后端”

这样的宽泛任务。

如果原任务过大，先根据执行策略拆成若干最小可验收子任务。

## 7. 输出位置

完整任务提示词保存到：

`docs/tasks/{任务ID}.md`

例如：

`docs/tasks/P0-02A.md`

同时在：

`docs/development-status.md`

记录：

* 当前已完成任务
* 下一任务 ID
* 下一任务执行模型
* 下一任务任务卡路径

## 8. 任务卡要求

任务卡必须已经是可以直接交给目标模型执行的最终提示词。

不得输出：

“请用户填写允许修改文件”
“请补充验收命令”
“请指定相关章节”

这些内容应由当前模型根据仓库和开发策略自行确定。

如果仓库确实没有足够信息，则写：

“执行本任务第一步先检查 XXX，并以实际结果为准。”

## 9. 完成当前任务后的固定动作

当前任务测试通过后：

1. 更新测试报告。
2. 更新 `docs/development-status.md`。
3. 保存本任务交接记录。
4. 根据开发执行策略确定下一任务。
5. 自动生成下一任务的完整 `docs/tasks/{ID}.md`。
6. 最终回答中仅告诉用户：

   * 当前任务 PASS / FAIL
   * 下一任务
   * 下一任务模型
   * 下一任务卡路径
   * 是否需要切换客户端/模型

不要要求用户再次手工填写第 8 节模板。
