# P4-SEARCH-PREVIEW-A 实现记录

日期：2026-10-04。状态：人物关联补充 IMPLEMENTED / 定向合成验证通过；原搜索查看器导航验收仍待做。

## 实现

- 搜索结果缩略图现在是键盘可聚焦的按钮；点击以原图预览接口打开大图对话框。
- 大图下显示“上一张”“下一张”和“第 N 张”，按当前搜索结果顺序导航；首尾按钮按可用结果状态禁用。
- 下一张越过当前已加载结果时，复用现有 `search_session_id` 与 `cursor` 加载下一页，再继续导航；不预取整库。
- 打开照片时复用 `GET /api/v1/assets/{asset_id}` 读取单张元数据，展示结果排名、资产编号、尺寸、格式、大小、规范化拍摄/文件时间、相机型号和原文件可用状态。仅用白名单字段，不渲染相对路径、哈希或原始 EXIF；详情读取失败仍显示排名和资产编号。
- 新搜索、重置或关闭对话框会使预览状态失效，避免旧分页结果切换到过期列表。分页失败时保留当前照片，用户可重试。
- 搜索页与人物页通过版本化静态资源参数刷新修改后的脚本/样式。
