## 实施

- 回忆 API 状态读取只读进度；首次请求、显式重试或取消后重进才启动任务。单低优先级 worker 在完成一个年份后自主排入窗口中的下一年，最多10年，仍为单待办、有界短快照和每条 SQL 75ms 预算。
- `DEFERRED` 通过有退避的等待恢复，不形成忙等；精选详情可优先打断尚未完成的发现，之后从未完成年份恢复。日期/图库修订变化会清除身份不匹配的待办与结果；取消和年份发布经同一条件锁协调。
- 卡片与精选继续使用有界进程内缓存。移除固定一小时 TTL；日期、图库过滤/收藏/拍摄时间规则修订及算法版本决定结果键。LRU 优先淘汰可重算的精选，保留完成窗口卡片。轮询不排任务，且不会因重复读取重复生成。
- 前端无卡片时每250ms读取进度，有卡片后600ms，`DEFERRED` 为900ms，终态停止轮询。离开页面、打开精选、预览路由前进/返回会使旧请求失效。重进仍请求服务端核验；返回409时清空旧身份卡片并重新读取首窗口。
- 保留日期资格、日/月候选上限、精选逻辑、普通合集和 viewer API；未改日期范围 SQL、schema 或公共接口。
