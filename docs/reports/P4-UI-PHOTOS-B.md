## LUNA High 受影响面复核与修复

独立只读复核发现并推动修复 4 项 P2：

1. 时间轴详情返回原先直接清除 pending 标记，没有重开资产锚点；现已将返回 anchor/asset ID 传给组件，恢复时按当前页面滚动位置加卡片 viewport 偏差校正，兼容详情页将窗口滚至顶部。扩展详情返回合成测试模拟当前 scrollY=0、恢复卡片 top=620、原 top=20，断言最终恢复 600。
2. 时间依据、桶、应用年月和直接定位原先等摘要完成后才 reset；现改为先立即 reset/递增分页 generation，再单独请求摘要。新增桶切换时迟到旧照片页不能覆盖新范围的行为测试。
3. 摘要加载/失败原先会覆盖照片分页错误；现摘要状态与分页状态使用独立提示区，年份刷新摘要不清除分页重试。新增年份刷新时保留分页错误的行为测试。
4. revision 不一致曾把摘要错误写入分页状态，显示冲突版本计数且摘要重试不能刷新照片页；现无论摘要先返回还是照片页先返回，revision 冲突都设置摘要错误与重试入口、清除不可信计数。重试会重新载入当前锚点附近的照片页和摘要，版本一致后计数恢复。新增两种响应顺序及重试恢复行为测试。

LUNA High 最终只读受影响面复核完成：此前的滚动恢复、日期切换 generation、摘要/分页状态隔离及 revision mismatch 计数与重试 findings 均关闭；未发现剩余 P2 或阻塞项。本结论是用户指定的 LUNA High review，不是 DS-H review 或 PASS。

## 2026-10-14 隔离合成产品浏览器续验

使用独立数据根 `.tmp/P4-UI-PHOTOS-B/browser/PhotoSearchData` 和本地产品服务 `127.0.0.1:18773`；所有写操作仅落到本任务合成来源。未接触 PhotoSearchData 之外的用户图库。

已通过产品浏览器观察：

- 来源切换：合成次来源为 4 张、切回全部图库恢复合成范围；点击照片页导航可回到统一时间轴。
- 分页与日期：127 条样本首屏 50 条，点击“加载更多”后看到第 2 页（资产 127 至 78）；按加入图库时间切到 2023 年并列出 11 月，点击“定位到年月”后落在该年月范围。
- 日期桶：合成照片当前 0 张“日期未知”、127 张“日期待就绪”。选未知桶显示“当前图库范围没有‘日期未知’的照片”；切到待就绪桶显示待就绪照片卡片；再选全部照片可返回。
- 管理交互：空名称被浏览器原生必填校验拦截，提示“请填写此字段。”；重复名称则被接受并显示保存成功，两条来源曾短暂同名；随后已将主来源恢复为“合成主来源”。删除来源按钮弹出原生确认框，文案说明只移除 PhotoSearch 记录、不删文件；已取消确认，来源仍存在。
- 请求路径：改名的浏览器服务日志为 `PATCH /api/v1/sources/1`、HTTP 200（2 次，均针对合成主来源）。访问日志不记录请求体或头，因此没有声称浏览器抓包核实其字段；原定向 UI/API 测试已覆盖 `display_name` payload 和 `X-CSRF-Token`，本轮没有重跑。
- 长列表：把合成主来源扩为 1,550 张唯一合成图片；图库管理显示文件、资产和在库位置均 1,550。全范围共 1,810 张（36 页余量）。入库时间轴连续滚动跨过第 30 页到第 31 页；从资产 ID 1810 滚到 ID 261 后，AX 树稳定显示 400 个照片按钮（约 8 页），同时出现“照片节点已回收；选择可按日期锚点重新定位”的锚点占位。详情页返回后仍恢复在资产 ID 261–660 的回收窗口。
- 资源日志：可见的浏览器服务日志片段有 11 次 `/timeline/assets` 请求；另一个 476 行但已截断的日志片段包含 450 个不同资产缩略图 GET（441 个 200、9 个 304）。这是截取片段计数，不代表完整会话总数或性能结论。

观察到的未闭环问题/门：照片按钮和可见缩略图经 AX/坐标点击均未打开详情（焦点留在照片按钮，URL 未变）；直接打开 `#/asset/660` 可显示详情，“返回浏览”可恢复长列表锚点，因此详情渲染及返回已见证，但从卡片点击进入仍未验证。多张缩略图在产品浏览器中呈现为纯色矩形，无法目视辨认图片内容。截图仅由浏览器工具显示，未能保存到仓库证据目录。首图 1.5 秒目标未测；200%/暗色观察未做；浏览器请求体/CSRF 头未抓包。

因此将本轮记为 `BROWSER_INTERACTION=PARTIAL_VERIFIED`；首图/缩略图视觉、卡片点击、可落盘截图及精确浏览器 CSRF/payload 仍为 `BROWSER_PENDING`。`PERF_200K_PENDING` 仍独立待验；本轮 1,810 合成照片仅用于长滚动/DOM 回收观察，不能代表 20 万性能。
