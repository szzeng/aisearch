## 实施内容

- 共享照片查看器在浏览器 Back 关闭后保留当前查看器历史标记；Forward 到同一标记时重开照片，不再压入重复历史项。查看器写入历史时合并现有 `history.state`，保留搜索历史项 ID、条件和快照 token，避免 Back 关闭照片后误跳出原结果页。
- 搜索页为不同的已提交搜索建立 History API 条目，并将范围身份纳入比较。Back/Forward 使用已有 sessionStorage 快照和服务端 session 校验恢复条件与结果，不重新提交搜索。取消固定范围后，旧快照保留到用户提交新范围；快照的滚动位置仍只在保存时采样。
- 从旧默认 `aisearch.search-return.v1` 快照恢复后，将快照关联到当前搜索历史条目并记录原表单/范围。替换查看器历史项时释放已关闭查看器的 `popstate` 监听器。
- 人物目录进入人物相册时建立可回退的 `person_id` 历史项；Back 恢复目录，Forward 复开人物相册。照片列表及人物相册内照片查看继续交由共享查看器处理。
- 照片浏览页将时间字段细则收纳到折叠说明，同时保留会影响筛选判断的时间来源；收藏页不显示无关说明。人物页空态改为指向现有“待整理”分类。
- 搜索请求启动时捕获已提交表单，异步响应与续页沿用该历史表单，避免请求期间编辑的未提交草稿和旧结果错配。更新受影响页面的资源缓存版本；新增/更新共享查看器、搜索历史、人物相册历史及提交表单竞态契约测试。
