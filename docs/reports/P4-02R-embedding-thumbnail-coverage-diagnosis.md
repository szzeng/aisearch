# P4-02R 只读诊断 — "有嵌入但没有就绪缩略图"的 379 个资产

用户 2026-09-27 要求只做**只读诊断**（不修、不看图）。工具：
`tools/diagnostics/p4_02r_decode_matrix.py`（只读 catalog/media 状态 + 只读判定链；不显示任何图像、
不输出绝对路径、报告输出到 `test-results/p4-02r-decode-matrix.json`）。

## 1. 结论（先行）

**不存在"语义探测比媒体契约宽松"的分歧。** 那 379 个嵌入是 **P4-02Q 修复之前**那一轮建库留下的
**历史残留**：当时建库入口还没有按媒体契约过滤，凡是 Pillow 能打开的都被送去编码；P4-02Q 加上过滤后，
这些资产已经**不再进入新目标**（真实库 dry-run 现在是 `targets=0`），但它们先前发布的 embedding 与
`CONFIRMED` 条目仍在索引里，而媒体层拒绝它们的**缩略图**。

## 2. 判定链（13 个抽样：6 `.jpg` / 6 `.cr2` / 1 `.dng`）

| 层 | 观测量 | 结果 |
|---|---|---|
| 文件头 | `media.decode.sniff_format` | `TIFF` ×7（CR2/DNG 是 TIFF 系）、`JPEG` ×6（MPO 的魔数就是 JPEG） |
| Pillow | `Image.open(path).format` | **`TIFF` ×7、`MPO` ×6** |
| 媒体契约 | `media.decode.plugin_format_decision` | `TIFF/decodable=False` ×7、`MPO/decodable=False` ×6 |
| 媒体契约（像素） | `media.decode.load_normalized(long_edge=320)` | **`FORMAT_UNSUPPORTED` ×13** |
| 媒体缓存记录 | `media.status.asset_media_states` | `thumbnail_code=FORMAT_UNSUPPORTED` ×13（与上一次完全一致） |
| **语义建库探测** | `indexing.semantic.image_eligibility` | **`TIFF/eligible=False` ×7、`MPO/eligible=False` ×6** ⇒ 与媒体契约**完全一致** |
| 适配器解码 | `PIL.Image.open(path).convert("RGB")` | **ok ×13** |

所以：`MPO`（多图 JPEG，手机常见，341 个 `.jpg` 属于此类）与 `TIFF` 系 RAW（CR2/DNG，36 个）被媒体契约
按"已识别但未验证"拒绝；而 Pillow 的**直接打开**可以读到（MPO 的首帧、RAW 的内嵌预览），
这正是修复前那一轮能成功编码的原因，也是"能搜到但网格里没有缩略图"的原因。

**我此前在 [P4-02P 报告](P4-02P-real-library-pilot-build.md) §5 写的机制（"语义侧魔数兜底更宽松"）是错的，
在此更正**：抽样证明两侧判定一致，差异来自"旧 embedding 残留"而非"判定分歧"。

## 3. 影响（准确表述）

- 379 个资产（341 `.jpg` = MPO、35 `.cr2`、1 `.dng`，另有 2 个同类别的 `.jpg`）在**文字/以图搜图里可被返回**，
  但 **网格/详情页没有缩略图**（媒体层拒绝）。
- 其余 2800 个图片资产缩略图正常。
- 索引口径与显示口径因此**暂时不一致**：索引里有 3179 个嵌入，可显示的是 2800 个。
- 这不是数据损坏、也不是模型问题；是"修复前发布、修复后未清理"的发布状态差异。

## 4. 可选处置（需要用户裁定的最小决定，本卡不实施）

| 选项 | 做法 | 代价 / 风险 |
|---|---|---|
| **A. 让 MPO 成为受支持格式**（推荐先做一半） | 在媒体契约里把 `MPO` 视为"多图 JPEG 的首帧"（`seek(0)`），缩略图与语义探测同时放行；用**客观对照**验证（同一文件按 MPO 首帧与按 JPEG 打开，尺寸/模式一致，且与 JPEG 直读的字节一致） | 需要扩一条已验证格式；收益是 341 张手机多图 JPEG 立即可见可搜；RAW（36 张）保持拒绝 |
| B. 只认"可显示" | 语义侧继续按契约拒绝，并把已发布的 379 个嵌入**从检索结果中排除** | 需要产品支持"删除/屏蔽已发布向量"的路径（当前 outbox 只有 UPSERT，无删除）；属契约变更，须单独 ADR/卡 |
| C. 接受现状 | 明确记为"可搜不可见"，写进试用说明 | 用户看到空网格会困惑；不推荐作为试用默认 |

RAW（CR2/DNG）建议继续拒绝：需要 RAW 解码/预览提取的独立验证，不属本卡。
