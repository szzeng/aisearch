日期：2026-10-13。状态：DEMO READY / 仅整体观感及合成点击演示。

用户要求生成可操作的页面，随后明确“简单的就可以了，不用那么复杂，主要演示整体观感”。交付 [离线单文件](../mockups/ui2-interactive/demo.html) 与 [使用说明](../mockups/ui2-interactive/README.md)，保留此前任务书改动；不实施产品八卡，不访问真实PhotoSearchData。

照片/人物/合集/地点/搜索/预览采用原浅灰白青绿布局，180条合成成员记录、本地生成SVG插画和确定性标签搜索；无外部图片/字体/地图/模型依赖。点击人物相册搜索只模拟该人物成员，不复制旧静态图上的第二输入框；数量不冒充20万实测数据。

简单检查：`node --check docs/mockups/ui2-interactive/model.js` 与 `node --check docs/mockups/ui2-interactive/app.js` 退出码0；本地HTTP入口返回200。真实浏览器看到首页和人物目录，进入张三相册后点“搜索此相册”并输入“海边”，显示张三固定范围和15条演示结果；预览打开，关闭后仍保留chip、搜索词与结果。最终独立单文件在浏览器显示桌面首页。只做上述基本观察与源码空白检查，不新增全仓/形式化pytest/JUnit。
