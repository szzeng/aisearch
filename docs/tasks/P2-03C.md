执行模型：**DS-L / DeepSeek V4.1 Flash / 低推理**（纯静态页面 + 既有 API 接线）。批量、

## 冻结实现范围

### 1. 静态地点页（依赖-free，不引入 Node/npm）

- 在既有 `src/photo_search/web/` package-data 目录内新增地点页面与其脚本/样式，并从
  `api/web.py` 提供一个页面入口（例如 `GET /places`，与 `/api/v1/places` 的 API 路径互不遮蔽），
  保留现有 `/` 页面、`/web/{asset}` 静态服务与路径穿越拒绝行为。
- 页面不得引用外链（CDN/字体/图片）、不得内联或回显本机绝对路径、不得携带任何精确坐标；
  与 P1-05 一致使用原生 HTML/CSS/JS，不引入构建链、包管理器或运行时依赖。
- 从 `/` 到地点页再返回的导航、键盘可达（Tab/Enter/Space）、640×900 窄视口无横向溢出。

### 2. 目录浏览与同名消歧

- 列表支持按名称/别名、kind、父级、祖先、生命周期的既有查询参数；keyset 分页游标绑定
  `catalog_filter_revision`，游标过期时显示“目录已变化，需重新加载”（`CATALOG_FILTER_REVISION_STALE`），
  不得静默拼接两版结果。
- 同名地点必须可区分：展示完整祖先链与稳定 `place_id`，不自动合并、不做名称猜测。
- 无包/坏包时目录与人工编辑仍可用（`/places/datasets` 的 `state` 用于展示缺包/坏包提示）。

### 3. 详情与编辑

- 创建 `city|attraction|custom`（country 来自数据包，UI 不得提供手工创建 country）；重命名与
  别名编辑必须携带 `expected_revision`，冲突（`PLACE_ASSIGNMENT_CONFLICT`）时提示重新加载并显示
  `current_revision`。
- UI 不提供改父级/合并/物理删除入口；若服务端返回“reparent 被拒绝”的校验错误，页面如实显示而不是
  隐藏该动作的存在。

### 4. 批量确认/取消（建议 → 人工归属）

- `place_state=suggested` 列表绑定 suggestion revision：过期（`PLACE_SUGGESTION_REVISION_STALE`）
  必须提示重查，不得把过期候选当成当前候选展示。
- 确认建议使用 `action=assign` + `origin=CONFIRMED_SUGGESTION`；取消归属使用 `action=unassign`；
  批量 ≤500、去重 asset_id、整批原子；界面必须展示逐批结果与失败批原因，不得显示假的部分成功。
- “全选结果”必须先冻结 asset_id 快照，不能在提交时重跑动态查询；必须明确区分
  `SUGGESTION_ONLY` 候选与有效人工归属。

### 5. 最近操作与撤销

- 展示 `GET /place-operations` 的 append-only 操作日志（分页），并允许对已提交操作发起 undo
  （`request_id` + `expected_operation_revision`）。
- `PLACE_OPERATION_NOT_UNDOABLE`（目标已被后续编辑）与 `PLACE_IDEMPOTENCY_CONFLICT`
  必须显示为可理解的提示并刷新受影响视图；undo 成功后目录/详情/建议状态同步刷新。

### 6. 数据包状态面板

- 展示 `GET /places/datasets` 的真实状态（`STAGED/VALIDATED/ACTIVE/RETAINED`、活动包、
  缺包/坏包 `reason`）与 suggestion revision；没有包时不得显示伪 ACTIVE，也不得把“无建议”渲染成
  “已归类”。

### 7. 隐私与边界

- 页面请求/渲染不得包含精确坐标（只在会话保护的 `/geo`）、绝对路径、原始 EXIF 或
  idempotency payload；错误信息仍经统一信封与 Redactor。
- 沿用既有 session/Host/Origin/double-submit CSRF 边界；页面不得新增绕过写入口的路径。

## 验收（B + 真实浏览器 smoke + C）

必需命令：

```text
uv run pytest -q tests/unit tests/integration
uv run ruff check .
git diff --check
uv lock --check
```

浏览器 smoke（真实端口 + Codex 内置浏览器，夹具在唯一 `%TEMP%` 目录；不得使用真实图库）：

1. 启动服务并走一次性会话链接，落地到 `/`，可导航到地点页。
2. 创建 `city`/`custom` 各一个，重命名、编辑别名（`expected_revision` 生效；过期 revision 提示）。
3. 制造/使用两个同名地点，确认列表能靠祖先链与 ID 区分；不出现自动合并。
4. 注册来源并扫描 `%TEMP%` 合成 GPS 照片，安装合成地名包（用 `tools/places/manage_dataset.py`），
   在建议列表看到候选；确认一条建议（origin 记录为 `CONFIRMED_SUGGESTION`）后该资产离开建议列表。
5. 批量确认/取消 ≤500 项：展示逐批结果；被拒绝的批次有明确原因。
6. 建议 revision 过期：手工触发一次变化后旧页面重查被拒（`PLACE_SUGGESTION_REVISION_STALE`）。
7. 最近操作列表 → undo 成功；对已被后续编辑的操作 undo 得到
   `PLACE_OPERATION_NOT_UNDOABLE` 提示。
8. 缺包/坏包状态：删除包文件后页面显示 `missing`/`invalid`，人工编辑与目录仍可用。
9. 窄视口 640×900 + Tab/Enter 走完主要动作；无横向溢出。
10. 页面与网络响应中不出现绝对路径与精确坐标（坐标只在 `/geo`）。

C 级（页面是发行资源，必须证明冻结包真的带上了它）：真实 onedir 构建 +
`tools/diagnostics/packaged_api_smoke.py`，并核对地点页面与其脚本/样式在 bundle 内以 200 提供、
无外链、无本机路径；如新增了新的 package-data 目录或修改了打包入口，必须显式记录并按卡补足 C。
