## 任务定位

P1-01～P1-05 交付了图库的持久身份、流式扫描、媒体产物、受控本地 API 与第一个可用前端，但 ADR-0002 里
「重复、移动、替换、断盘、重映射、重启」这一组语义**只在单元/集成层面各自验证过片段**，
没有作为一次可独立验收的对抗性闭环被系统执行。

P1-06 交付的是**验收闭环，而不是新功能**：用 `%TEMP%` 下的合成夹具，逐条证明冻结规则在真实文件系统
事件下成立，并把任何真实的语义违反、误判或数据损坏变成失败证据。实现改动只允许发生在「测试证明
存在与冻结契约冲突的缺陷」时，且必须是最小修复。

本任务仍然**不做**：搜索/以图搜图、人物与人脸、OCR、模型/索引/outbox/升级回退 API、调度器
pause/resume、P2 全量任务协议、前端功能扩展（P1-05 已交付）、任何 `taken_at`/EXIF 拍摄时间列或迁移。

## 用户场景

- 用户把同一张照片复制到两个目录：图库里应只有**一个**资产，两个位置都指向它；删除其中一个副本不应该
  让资产变成「原文件不可用」。
- 用户把照片从一个子目录移到另一个子目录（同一来源内）：资产身份不变，新位置 PRESENT、旧位置 MISSING，
  不产生第二个资产，也不复制机器结果。
- 用户用一张新照片覆盖旧文件（内容不同）：**不得**把新内容静默绑定到旧资产；替换后要么重新确认内容身份，
  要么把该位置判为需要重新确认，绝不出现「旧指纹指向新文件」。
- 用户拔掉外接盘/断开网络盘（来源整体离线）：所有位置保持原状态或按规则标记离线，
  **绝不**因为一次扫描看不见文件就批量判定照片被删除；已有缩略图仍可浏览，并明确提示原文件不可用。
- 用户把来源根目录换到新的挂载点（盘符变化/目录改名）：通过重映射保持身份与位置绑定，
  不逐条替换绝对路径。
- 用户在扫描进行中强制结束进程并重启：重启后同一 `scan_run` 被接管恢复，不产生重复资产/位置，
  也不把未确认的内容写成成功结论。

## 必须交付

### 1. 对抗性验收测试（主体交付物）

在 `tests/integration/` 新增（或按需扩展同名新文件）针对下列场景的**可独立运行**闭环；每个场景都必须
断言具体的库内事实，而不是只看退出码：

1. **重复内容**：同一内容出现在同一来源的多个路径、以及不同来源中；断言只有一个 `asset_id`、
   位置数与预期一致、`sha256` 唯一、机器结果（媒体产物路径按内容寻址）共享，
   且删除其中一个副本不改变资产的 PRESENT 结论。
2. **移动**：同一来源内移动/改名；断言新位置 PRESENT、旧位置 MISSING、`asset_id` 不变、
   资产数为 1、媒体产物不需重新生成（同一内容寻址路径）。
3. **替换**：用一个内容不同的文件覆盖已有路径；断言不出现「旧 `sha256` 指向新文件」，
   新内容最终获得正确身份，且失败/未确认状态是显式的（不得静默成功）。
4. **断盘/离线**：来源根目录不可达（重命名或删除）后触发扫描；断言**不产生**删除结论
   （MISSING 只能由完整成功的扫描产生，离线/不可达阶段不得写成删除），资产仍可列出、
   已有产物的状态与原因仍可读。
5. **重映射**：来源根改变（新挂载点/改名）后，身份与位置绑定保持；按第「开始前必须先检查」第 5 项
   的结论执行，并明确记录实际验证到哪一层。
6. **重启/中断恢复**：扫描中被中断（可用既有 `interrupt_after` 等注入点）后重新发起，
   断言接管的是同一 `scan_run`、`attempts` 变化符合冻结规则、无重复资产/位置、
   且未确认内容不会被写成成功。

## 正常行为 / 异常行为 / 边界情况（验收时逐条覆盖）

**正常行为**

- 重复内容共享一个资产、多个位置；媒体产物只按内容生成一份。
- 同一来源内移动/改名：新位置 PRESENT + 旧位置 MISSING，`asset_id` 不变，资产数不变。
- 完整成功的扫描才产生缺失结论；成功扫描后 `last_successful_scan` 指向该 `SUCCEEDED` 扫描。
- 重启后同一 `scan_run` 被接管恢复，行数不增长。

**异常行为**

- 来源根不可达（断盘/离线）时不得产生删除结论，也不得把整批照片判为缺失。
- 内容被替换后不得静默沿用旧身份；未确认状态必须是显式的。
- 扫描中断/进程被杀后恢复同一逻辑扫描，`attempts` 依据冻结规则单调变化，不出现并发双扫描。
- 不可达/权限失败位置与「确认缺失」位置在状态上可区分。

**边界情况**

- 0 个文件、1 个文件、>1000 个文件的来源；同内容跨来源；
- 同一次扫描内同一路径先出现后消失（枚举与被确认之间的窗口）；
- 中文、空格、`>220` 字符路径；只读原文件；空目录；
- 目标位置已存在同名不同内容文件（替换与撞名并存）；
- 来源根被改名后立刻扫描（旧根不存在、新根存在）；
- 数据库在扫描中被第二个进程打开（沿用 P1-02 记录的跨进程写者约束，不新增承诺）。
