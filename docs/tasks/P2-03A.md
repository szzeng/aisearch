## 冻结实现范围

### 1. 0004 地点核心 migration

新增一个连续 `0004_*` 并把支持版本推进到 4。P2-03A 只创建本闭环需要的对象：

- `places`、`place_aliases`、必要的 `place_external_refs`（允许为空，供未来包稳定映射，但本卡不导包）；
- `asset_geo_facts`（每 asset 一个当前事实，绑定 location/input revision/processor/raw checksum）；
- `asset_place_assignments`、只追加 history、`asset_place_exclusions`；
- `place_operations`、`place_operation_items`；
- singleton `catalog_filter_revision` + revision events/受影响资产记录；
- singleton `place_suggestion_revision` 可初始化为 0，P2-03A 不创建 resolution/candidate 或 dataset 表，
  也不递增 suggestion revision。

SQLite 能表达的 PK/FK RESTRICT、NOT NULL、UNIQUE、枚举、范围和模式组合全部下沉。place name 不唯一；
country 无父；parent!=self；完整类型矩阵、ACTIVE parent 与祖先环由同一短事务的递归 CTE 校验。坐标
还须在 Python 拒绝 NaN/Infinity。v3→v4 必须备份、单事务、失败保持 v3、旧表/行逐列不变；缺件与
higher schema 继续零写拒绝。

### 2. GPS 事实

- 实现版本化 `non_model + CPU_PREFERRED` GPS extractor；不伪造 model/weights/space/dimension。
- 只通过已登记 `file_locations` 的受控路径读取；复用读取前/读后 stat + asset SHA/input revision 核对，
  不信任请求给出的路径。文件变化或来源不可用不得提交旧事实。
- 区分 `VALID/ABSENT/INVALID/UNSUPPORTED_CRS/SOURCE_UNAVAILABLE` 与
  `WGS84/ASSUMED_WGS84/UNSUPPORTED/ABSENT`；`(0,0)` 合法，南/西半球、非法分母、非有限、越界、
  未知 datum 分支明确。
- ABSENT 是 `SUCCEEDED + artifacts=[]` 或规范 structured 空事实（以 ADR-0005 schema 的精确形状为准），
  不得把离线伪装成 ABSENT。坏 GPS 只隔离地点任务，不阻塞浏览/缩略图/语义。
- 精确坐标只在受保护 artifact/catalog 与 session 保护的 `/assets/{id}/geo` 返回；不进普通日志、
  URL、错误 details、诊断、反馈或 LanceDB。

### 3. 地点目录

- 稳定整数 place_id；四类 `country|city|attraction|custom`；生命周期 ACTIVE/RETIRED；名称和别名
  可改但不换 ID。
- 同名允许并存，列表返回完整祖先链和 ID 供消歧；用户可创建 city/attraction/custom，country 的
  手工创建按 ADR-0005 限制。PATCH v1 只开放改名/别名，不开放 reparent/merge/物理删除。
- 退休时若有 ACTIVE 子节点、有效 assignment 或 exclusion，返回 `PLACE_REFERENCED`；否则软退休。
- `GET /places` 支持 name/alias、kind、parent、ancestor、lifecycle 的稳定 keyset 分页；游标绑定目录
  revision。祖先展开按 asset 去重，重复文件位置不能重复计数。

### 4. 人工控制、批量与撤销

- 每 asset 一个当前控制行：`AUTO_ALLOWED`、`MANUAL_ASSIGNED`、`MANUAL_UNASSIGNED`；只有 ACTIVE
  MANUAL_ASSIGNED 是有效地点。人工 assign/unassign 都是锁，重扫/GPS 晚到/profile 回退不能覆盖。
- assign A→B 激活 A exclusion；显式 assign B 可解除 B exclusion且只解除目标；unassign 排除原地点；
  restore_auto 保留排除，不自动采用建议。
- 所有写请求使用 LOCAL_USER、request_id、规范 payload SHA、expected revision；同 request+同 payload
  返回原结果且不增 revision，不同 payload 返回 `PLACE_IDEMPOTENCY_CONFLICT`。
- 单项和 1～500 去重 asset 批量先全量校验再单事务提交；0、重复、499/500/501、逐项 revision 冲突
  有具名反例。任一错误整批零写，不返回假部分成功。
- undo 是新补偿 operation，要求原 COMMITTED/未撤销且所有目标仍等于 after revision/state；成功产生
  更大 revision并恢复 before 语义，冲突整批 `PLACE_OPERATION_NOT_UNDOABLE`，不删历史。
- 权威 assignment/名称/层级/可见检索文本真正变化时，同一事务递增一次 CatalogFilterRevision，写
  event，并调用 P2-03 `schedule_projection_refresh` 为已有确认向量排入刷新；仅 GPS 事实、空操作或
  suggestion 不递增。

### 5. 纯 SQLite API 与筛选

实现本卡可独立验收的冻结接口：

```text
GET    /api/v1/places
POST   /api/v1/places
PATCH  /api/v1/places/{place_id}
GET    /api/v1/places/coverage
GET    /api/v1/assets/{asset_id}/geo
GET    /api/v1/assets/{asset_id}/place
PUT    /api/v1/assets/{asset_id}/place-assignment
POST   /api/v1/place-assignments/batch
GET    /api/v1/place-operations
POST   /api/v1/place-operations/{operation_id}/undo
GET    /api/v1/assets?...place_ids/include_descendants/place_state...
```

`GET /places/datasets`、PlaceResolution/候选、附近城市和 dataset 状态留 P2-03B；若为前端契约必须出现，
只返回 capability 明确 unavailable 的空只读投影，不能建假 ACTIVE 包。`POST /search` 的语义组合留
P2-05/06，不在本卡扩张。

PlaceFilter：place_ids 内 OR，默认含后代；与现有 source 等条件 AND；assigned/unassigned/
manual_unassigned 正确，suggested 在没有 P2-03B 候选时为空；给 place_ids 时 state 只允许 any/assigned。
接口沿用 session/Host/Origin/double-submit CSRF、统一错误信封与 Redactor；写入口不得绕过单写者。

## D 级验收

全部图片/数据库/坐标/目录使用唯一 `%TEMP%` 夹具；GPS JPEG 由测试生成，不读真实照片、不联网。
至少新增地点 migration/core/API/GPS/fault tests，并逐项映射：

1. v3→v4 正常/备份/中断回滚/缺件/higher-version 零写；旧 artifact/outbox/index/job/asset 行逐列不变。
2. GPS：无字段、(0,0)、南西半球、合法 WGS84、ASSUMED、非法分母、NaN/Infinity/越界、未知 datum；
   原图离线不是 ABSENT，文件读中变化/迟到 lease 零事实副作用。
3. 地点：四类、同名不同层级、深层祖先、名称/别名搜索、类型矩阵、自环/祖先环、退休引用保护；
   PATCH 不开放 reparent，稳定 ID 不变。
4. assign→unassign→重启/重扫→restore_auto→再 assign；锁、origin、排除和 revision 逐项正确，GPS/晚到
   自动结果不能覆盖人工状态。
5. request_id 同 payload 幂等、不同 payload 冲突；空/重复/499/500/501、任一 expected revision 冲突
   的批量全原子。
6. undo 无后续编辑时补偿成功且 revision 增大；任一目标已后续编辑时整批拒绝、历史不删。
7. CatalogFilterRevision 触发矩阵；同事务 outbox projection refresh；事务注入失败时 assignment/
   history/exclusion/operation/revision/outbox 全回滚。
8. 纯地点筛选：后代、同名、无地点、manual_unassigned、重复位置去重；suggested 不伪装 assigned；与
   source 条件 AND。
9. API session/Host/Origin/CSRF、错误码、分页 revision、字段脱敏；精确坐标只在 session `/geo`，
   日志/URL/错误/diagnostics/outbox/Lance 无坐标。
10. GPU capability 缺失时 GPS/地点筛选与人工写仍可用；`artifacts=[]` 和 structured 结果均正常。
