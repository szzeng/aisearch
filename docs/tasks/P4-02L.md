## 必须交付

1. 先固定SDK版本、Python3.12.10、seed、维度、归一化、度量、数据形状、数据/查询哈希。实际构建向量builder、记录参数序列化；按本版本可用API建立独立ANN表，记录执行计划/索引状态，排除静默精确扫描。探测类型支持，拒绝/超时如实记录，不能照当前在线文档假设接口。
2. 小档先证明参数真实执行，再逐步8万→10万→30万；数据采用确定性归一化512-D合成向量，至少两种分布。设置有界时间预算，前档失败停止扩大，不把超时当0ms或缺日志当成功。
3. 每档同样查询集合、训练/评测分离；独立精确oracle用同候选向量和度量，固定全序与并列策略。比较exact、可用IVF_FLAT和IVF_PQ；同索引单变量扫probe/refine，再看分区/量化。参数不得超过有效分区而不解释。保留所有失败配置，不只报最好结果。
4. 输出Recall@20/50、P50/样本P95、样本数、单查询数据、训练/索引构建时间、RAM/磁盘、新增未索引量、冷首查与暖查询。交错执行exact/ANN对照，至少每配置30条固定查询；样本不足明确P95的不稳定，不写发布验收。
5. 普通宽集合与少量/高选择性候选预过滤分别测，固定“资格集合内”的oracle。加入未索引新增、并列、较近但被筛掉的行。**不能全库Top-K后过滤**，refine也不能追回未召回候选。成员正确性与ANN相对召回分开记录。
6. 真实照片向量只可复用已明确授权、已登记的评测产物，先核对来源/空间与范围；没有则完成合成闭环，真实质量BLOCKED，不临时扫描照片。合成低/高Recall均不可泛化为模型语义质量。
7. 最终给出参数可用性更正、速度/召回曲线、复现命令、适用范围、最小失败例、内存与质量代价；不预设“ANN一定赢”。若没有可用配置，记录证据并继续当前精确路径，不引入新后端。
