## 冻结实现范围

### 1. 0005 数据包与解析 migration

- 新增连续 `0005_*` 并把支持版本推进到 5；v4→v5 必须备份、单事务、失败保持 v4、旧表/行逐列不变；
  缺件与 higher schema 继续零写拒绝。
- `geo_datasets`（不可变内容、来源/许可/归属、坐标基准只接受 WGS84、覆盖、兼容 schema 区间、
  `STAGED/VALIDATED/ACTIVE/RETAINED` 状态、数据目录内相对目录、时间戳）；
  `geo_dataset_files`（`(dataset_id, relative_path)` 唯一、角色、size、checksum、禁绝对路径与 `..`）；
  `active_geo_dataset`（单例，只指向 VALIDATED/ACTIVE）。
- `place_resolutions`（不可变机器产物：asset/geo fact/processor/dataset/config/input revision、
  控制 revision 快照、`CANDIDATES|NO_CANDIDATE`、suggestion revision）与
  `place_resolution_candidates`（rank 唯一、固定 `SUGGESTION_ONLY`、`NEARBY_CITY_POINT` 依据）。
- 数据包版本、suggestion revision、embedding space、index generation 与 SearchProfile 继续彼此独立；
  切包不重算图文向量。

### 2. 离线地名包

- 只读包位于应用数据目录内的唯一 staged/active 目录；普通启动**不联网**，不下载、不上传照片或坐标。
- 导入流程：manifest 解析 → 许可/归属/坐标基准/兼容 schema/覆盖校验 → 逐文件 size+checksum →
  格式与层级引用 → fsync → `VALIDATED`；激活在一个 SQLite 事务内改指针与状态。
- 缺包/坏包/半包返回 `PLACE_DATASET_MISSING`/`PLACE_DATASET_INVALID`，只阻塞解析；人工地点创建、
  既有名称/层级显示、人工归属、筛选与操作历史继续可用。
- 崩溃前未提交则旧指针继续有效；提交后重启按新指针复核；坏包可原子回退到上一 VALIDATED/RETAINED 包。
- 被活动指针/解析/在途 job/回退窗口引用的包不可清理；清理必须返回 `PLACE_REFERENCED`。

### 3. 附近城市建议（suggestion-only）

- 版本化 `non_model + CPU_PREFERRED` 解析执行器，不伪造 model/weights/space/dimension。
- 只消费 P2-03A 的当前 GeoFact（`VALID` 才产生候选；`ASSUMED_WGS84` 只能产生待确认建议；
  `INVALID`/`UNSUPPORTED_CRS`/`ABSENT` 为 `NO_CANDIDATE` 成功空结果）。
- 候选固定 `match_basis=NEARBY_CITY_POINT`、`confidence_basis=DISTANCE_ONLY`、
  `disposition=SUGGESTION_ONLY`；多候选/同名/海上/无匹配可为空或多项；不证明行政包含关系，
  不自动命中景点。
- 解析器**从不**写 `asset_place_assignments`；晚到结果只在 lease/input revision 资格通过后保存为
  机器产物，即使看到旧控制 revision 也不得覆盖人工 `MANUAL_ASSIGNED`/`MANUAL_UNASSIGNED`。
- 候选可见集合变化时递增 `place_suggestion_revision`（不递增 `catalog_filter_revision`）；
  过期会话返回 `PLACE_SUGGESTION_REVISION_STALE`。
- 确认建议走既有 `assign` 用例，可记 `origin=CONFIRMED_SUGGESTION`；人工锁与排除语义不变。

### 4. API 与能力

- `GET /api/v1/places/datasets` 返回真实包状态（`STAGED/VALIDATED/ACTIVE/RETAINED`、活动包、
  缺包/坏包原因）；没有包时不得伪造 ACTIVE 包。
- `GET /api/v1/assets/{asset_id}/place` 与 `.../geo` 增加当前建议状态/候选摘要（坐标仍只在会话保护的
  `/geo`）；`/assets?...place_state=suggested` 必须绑定 `suggestion_revision` 并返回真实候选集，
  不得伪装成已归属。
- 接口沿用 session/Host/Origin/double-submit CSRF、统一错误信封与 Redactor；写入口不得绕过单写者。
- 数据包准备/导入是**显式本地工具**（例如 `tools/` 或 CLI 子命令）；普通应用启动不联网。

## D 级验收

全部夹具使用唯一 `%TEMP%` 目录；地名包用固定公开小数据集的**极小合成子集**（或在用户确认后使用
固定快照），不读真实照片、不联网。至少新增 0005 migration、数据包生命周期、解析器、候选/建议状态、
API 与故障注入测试，并逐项映射：

1. v4→v5 正常/备份/中断回滚/缺件/higher-version 零写；旧表/行逐列不变。
2. manifest 校验：缺字段、许可/归属缺失、非 WGS84、兼容区间不符、文件 size/checksum 不符、
   绝对路径或 `..`、角色/格式/层级异常；坏包不激活且旧指针不变。
3. 激活/回退：`STAGED→VALIDATED→ACTIVE`、提交前崩溃、提交后重启复核、坏包回退到上一
   VALIDATED/RETAINED；被引用包不可清理（`PLACE_REFERENCED`）。
4. 解析分支：无包/缺包 → `PLACE_DATASET_MISSING` 只阻塞解析；人工创建/既有名称/人工归属/筛选仍可用。
5. 候选：`VALID` 产生候选，`ASSUMED_WGS84` 只产生待确认，`ABSENT`/`INVALID`/`UNSUPPORTED_CRS`
   为空结果；`disposition=SUGGESTION_ONLY`；多候选/同名/边界/海上/无匹配均可复现。
6. 人工优先：建议永不写 `asset_place_assignments`；晚到解析不覆盖 `MANUAL_ASSIGNED`/
   `MANUAL_UNASSIGNED`；`suggestion_revision` 变化但 `catalog_filter_revision` 不变。
7. 确认建议：`origin=CONFIRMED_SUGGESTION` 的归属进入人工锁，重扫/切包/回退后保留。
8. API：包状态、建议状态与候选摘要不泄露坐标（只在 `/geo`）、不泄露本机路径；
   `place_state=suggested` 绑定 suggestion revision 且过期返回 `PLACE_SUGGESTION_REVISION_STALE`；
   session/Host/Origin/CSRF 与错误码正确。
9. 故障注入：解析事务中断、候选写入与 suggestion revision 同事务、数据包文件被篡改/删除后的行为、
   清理保护。
10. GPU 缺失时解析/建议/人工写全部可用；`artifacts=[]` 与 structured 结果都正常。
