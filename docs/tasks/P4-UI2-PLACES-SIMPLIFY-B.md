## 目标与边界

只用 Codex 内置浏览器，在 `127.0.0.1` 的真实应用上执行以下两条隔离合成数据路线，关闭 A 卡的 `BROWSER_PENDING`：

1. `/places` → 检查默认仅见地点相册与唯一「整理地点」入口 → 进入整理 → 默认显示识别建议 → 切换高级维护/历史面板 → 返回地点相册，确认筛选和列表位置仍在。
2. `/places` → 进入合成地点详情 → 打开照片预览并关闭 → 返回相册列表；同时观察「更多操作」入口默认收起及明确的三种纠错语义。

遵循 `AGENTS.md` 的启动和会话流程：先检查最新代码/状态及已有隔离 fixture，启动时不加 `--open-browser`，使用一次性链接在同一 Codex 内置浏览器打开并确认认证 API。截图可导出时保存 1–2 张至 `docs/reports/artifacts/`。链接认证、浏览器工具或 fixture 不支持的步骤记为具体阻塞，不反复重试，不用静态 DOM 代替产品浏览器证据。不得访问真实图库或真实照片。
