- **状态**：IMPLEMENTED / 定向验证通过 / BROWSER_NOT_RUN_USER_REQUEST；整卡验收待浏览器路线。
- **优先级**：P2；小范围 UI 体验增强。
- **推荐模型**：GPT-6 Medium（用户在 Codex 中手动选择）；仅前端/只读行为，按仓库策略进行限域复核。若触及地图成员协议、数据修订或数据库则停止扩范围，另立任务。
- **代码基线**：`szzeng/aisearch` / `master`，以执行当天最新 HEAD 为准。优先阅读 `AGENTS.md` → `docs/development-status.md` → 本卡 → 本卡列出的直接相关代码/测试；不得覆盖并行任务的修改。

## 1. 目标与用户可见行为

在地图相册中，**鼠标移动到右侧某张照片上，左侧地图在该照片真实 GPS 位置出现显眼但不过度夸张的高亮点；离开时恢复原样**，使用户立即辨认照片对应的地点。

| 场景 | 必须表现 |
| --- | --- |
| 进入右侧照片卡（含图片、按钮、留白） | 精确经纬度出现临时高亮；中心醒目、白色细描边、柔和外环。建议中心视觉半径约 11–12 CSS px、外环约 16–20px，最终以地图两种底图实际可辨认为准 |
| 在同一卡的图片/按钮间移动 | 高亮稳定，不闪烁、不反复重建 |
| A → B 快速滑动 / 离开卡片 | 只保留当前卡片的标记，离开后恢复；旧标记不残留 |
| 地图单点、MapLibre 聚合、网格聚合 | 始终标在**具体照片的 GPS**，不误用聚合中心，也不自动展开聚合 |
| 两张照片坐标完全相同 | 两次高亮位于同一坐标，允许完全重合，绝不人为偏移 |
| 键盘 Tab 聚焦照片里的原有按钮 | 可以获得同等定位提示；卡内按钮之间切换时稳定，离开后清理 |
| 点击照片、打开/关闭共享查看器、Esc、返回 | 原行为保留；打开查看器应立即清除照片 hover，不能在遮罩后留下定位点 |
| 无地图、GPS 不合法、触摸设备 | 正常浏览与打开照片；不报错、不出现触摸后粘住的悬停状态 |

**不变量**：仅改变局部地图标记和必要的当前卡视觉状态。悬停不得 `flyTo/easeTo/jumpTo`、自动缩放/平移、滚动列表、展开聚合、排序、重载列表、改变当前 bbox、成员版本、游标或查看器状态。鼠标在地图点上原有点击、拖拽、聚合数字点击保持可用。不得引入任何 hover 网络请求。

## 2. 最新代码锚点与真正的边界

实现时核实以下现有数据与调用链，而不是另做地图数据总线：

- `src/photo_search/api/map_api.py` 的 `GET /api/v1/map/assets` 已按成员返回 `asset_id, latitude, longitude`，默认与可信拍摄时间排序、分页/网格 cell 的资产行均有坐标；不需要额外查询位置详情。
- `src/photo_search/web/map.js` 的 `drawGrid(data, reset)` 同时渲染视口首屏、追加页及 cell 明细的 `article.tile`；在**整张卡片**上统一接事件，比只监听 `img` 可靠。
- `GET /api/v1/map/points` 在当前范围 **≤5000** 张时给出照片点、超过后转为最多约 1000 个网格 cell。悬停仍以右侧单张资产坐标为准，不能拿 `cell_id`、网格中心或 feature 显示点猜具体照片 GPS。
- `loadClusterLeaves()` 用 MapLibre `getClusterLeaves()` 获取聚合成员；目前渲染的是**纯文字按钮而非 tile**。其 feature 的 `geometry.coordinates` 可直接用于定位，但必须验证顺序 `[longitude, latitude]`，并保留 `loadClusterLeaves` 的分页与原按钮点击行为。
- `labels()` 已用独立 `.map-count` DOM marker 展示聚合数字；新增定位层不可劫持它的事件、复用它的计数或顺手重构其生命周期。
- `refresh/schedule/fetchSnapshot/openCell/loadMore/fallback` 有视野/序号/成员版本控制。悬停不能导致刷新；刷新、范围变化或旧列表替换必须清理原激活态，不允许旧异步结果复活标记。

## 3. 实现建议（首选最小方案）

### A. 一个可复用的临时标记

在 `map.js` 内维护**最多一个**只用于高亮的 MapLibre `Marker`（或等效的 O(1) 单点 overlay），懒创建、随当前照片改变坐标，未激活时隐藏或移除。不能为 48 张照片分别创建 marker、source 或 layer，也不能随鼠标每一帧反复创建 marker。

- 仅接受有限经纬度且满足 `-90 ≤ lat ≤ 90`、`-180 ≤ lng ≤ 180`；`0`、负坐标均合法，禁止 `if(lat && lng)` 等误判。
- Marker 的 DOM 应设置 `pointer-events: none`；必要时通过局部层叠控制让高亮位于普通点/聚合点上方，但依然可点击下层原地图点。不能设置遮挡全画布的 overlay。
- `map.css` 增加例如 `.map-photo-hover-marker` 的局部样式；可为当前右侧卡加不改变尺寸的 outline / 背景。支持浅色/暗色页面、标准/卫星底图与 `prefers-reduced-motion`。
- 运动方式优先直接切换坐标、短透明度过渡；不进行动画排队、连续脉冲或计时轮询，避免快速滑动留下旧点。
- 地图实例不存在、尚未就绪、已降级或生命周期结束时安全 no-op；旧 Marker 与监听不得随重新初始化累积。

### B. 统一触发与清理

提炼唯一的照片→坐标高亮入口，`drawGrid()` 的卡片与 `loadClusterLeaves()` 的成员按钮都使用它：

1. 鼠标真正 `enter` 卡片才显示，`leave` 时清理；不要监听全局 `mousemove`，也不要因为卡片内子元素切换而闪烁。
2. 键盘 `focusin/focusout` 兼容卡内两个按钮；用 `relatedTarget/contains` 或等价逻辑保证焦点在卡内移动不消失。区分触屏点击导致的焦点与键盘焦点，触屏不得永久悬停。
3. 同时存在鼠标与键盘焦点时，明确优先级：**当前鼠标卡 > 当前键盘焦点卡**。清理其中一个来源，不应错误消灭另一个仍有效的高亮。
4. 列表 `reset`、`refresh`、`schedule`、`openCell`、排序切换、切换当前聚合成员列表、地图失效/重建、查看器打开时清理；地图移动及视口更新时旧激活态不得带到新 bbox。必要时处理右侧列表滚动导致的指针下卡片更替，避免停在旧卡。
5. 追加页的新卡立即支持高亮；不要每次加载后向整页重复注册监听。迟到的旧事件/响应必须受当前 DOM 与现有 `sequence/member_version` 生命周期保护。
6. 严格复用现有 `openAsset`、按钮 `onclick`、聚合展开行为和原有事件传播；不要将 card 变成新的点击导航入口。

**实现取舍**：为了简化，允许用单一 `Marker` 直接描绘真实坐标，而不是修改 MapLibre 原始 `singles/clusters` 图层上的圆点尺寸。这样对 >5000 的网格、同坐标点以及叶子成员行为更一致，并且无需反查当前渲染 feature。

## 5. 最小但能抓住回归的验收

采用本机隔离合成样本（可用已有 Node/JS MapLibre stub + 10–40 张合成 GPS 照片）验证**事件触发后的真实标记坐标/可见性/对象个数/调用次数**，不能只做源代码字符串断言。

| 编号 | 操作与断言 |
| --- | --- |
| H01 | 鼠标 A 卡→卡内图片/按钮→B 卡→离开：高亮坐标与 A/B 精确一致、同卡不闪烁、最后清理；地图 center/zoom 不变 |
| H02 | Tab 进入 A 的两个按钮、离开、与鼠标来源交错：焦点回退规则正确，原按钮仍可打开照片 |
| H03 | 普通分页追加/切换可信拍摄时间排序/打开 cell：所有已加载卡均高亮对应 GPS；没有 hover HTTP 请求 |
| H04 | >5000 照片进入 grid：选中成员显示真实坐标而不是 cell 中心；聚合数字仍可点击 |
| H05 | MapLibre cluster leaves 分页、完全同坐标照片：叶子按钮有坐标、成员仍能分别打开 |
| H06 | (0,0)、负经纬度、无效/缺失坐标、无 MapLibre / fallback：合法点显示，非法静默，照片操作不受影响 |

| H08 | 标准/卫星底图、浅/暗主题、窄视口、触摸模拟：标记可辨、无误拦点击；触屏不粘住状态 |
