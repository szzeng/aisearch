## 目标

用真实 GeoNames 数据生成一个个人使用的亚洲地名包，并导入：

```text
D:\SZ\project\PhotoSearchData\places\datasets
```

只验证现有：

```text

```

可以使用真实数据正常工作。

## 1. 数据范围

使用 GeoNames：

```text
cities500
alternateNamesV2
countryInfo
```

第一版只保留主要亚洲国家/地区：

```text
CN HK MO TW
JP KR MN
SG MY TH VN PH ID KH LA MM BN
IN NP LK BD PK BT MV
```

中国优先。

名称优先：

```text
简体中文
→ 其他中文
→ GeoNames 主名称
→ 英文
```

## 2. 实现

增加一个简单准备工具，将 GeoNames 原始文件转换成现有 PhotoSearch 地名包格式。

输出继续使用现有格式：

```text
manifest.json
places.jsonl
aliases.jsonl
hierarchy.jsonl
LICENSE.txt
```

然后复用现有：

```text
manage_dataset.py
```

完成：

```text
build / import / validate / activate
```

不修改现有地点数据结构和解析协议。

## 3. 最小验证

1. 数据包能够成功生成；
2. `validate` 通过；
3. 能成功 `activate`；
4. 检查几个已知坐标，例如：
   - 杭州；
   - 上海；

5. `nearby_cities()` 返回合理城市名称；
