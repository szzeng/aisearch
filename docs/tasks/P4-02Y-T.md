## 5. 真实个人试用 smoke

在用户已授权的真实图库上，只做非破坏性操作。

### A. 启动

- 启动 PhotoSearch.exe；
- Web UI 正常打开；
- 能看到来源/图库/搜索入口。

### B. 刷新

- 使用 P4-02Y 的“刷新图库”；
- 能进入 SEARCH_READY；
- 不要求等 face/OCR/GPS 全部完成。

### C. 搜索

随手做 **5～10 个真实中文查询**。

只看：

- 能返回结果；
- 图片能显示；
- 页面没有明显卡死；
- 结果有实际使用价值。

不做 Recall/nDCG，不跑 30 样本。

### D. 小增量

在一个安全来源中新增约 **5～20 张真实图片**：

- 再点刷新；
- 到 SEARCH_READY；
- 能搜到新增图片。

### E. 重启

- 正常退出；
- 再启动；
- 原来的图库、索引和搜索仍可用。

只有以下情况才阻止开始试用：

- 打包产物无法启动；
- 当前真实模型在包内不可用，导致核心文字搜索不能用；

- 原图被修改/删除；
- Web 基本无法操作。

处理方式：
