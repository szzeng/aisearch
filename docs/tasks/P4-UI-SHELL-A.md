## 2026-10-13 相册搜索快捷入口的外壳职责

新增「搜索此相册／搜索此合集／搜索此地点」属于具体相册标题区的**上下文动作**，不是第二个主导航项，也不是页头全局框的替代。A 只负责页头**唯一全局搜索输入位置、焦点/窄屏/深链容纳**；不得在 A 实现 `scope` 参数解析、额外搜索表单、相册按钮或真实内容搜索。将带范围的跨页动作留给 C/SEARCH-MAP；原人物相册搜索在 D 之前/期间仍须可用。C 接通后，非结果页普通聚焦默认全库；结果页保留已有固定范围，明确取消 chip 才解除。只有相册快捷动作主动选择范围。首页/人物/地点等没有已接通 scoped 能力时不得先渲染“能点击却不执行”的入口。

## 允许范围与实现要求

- `web/index.html/search.html/persons.html/places.html/map.html` 的页头/导航外壳；`styles.css` 和页级 CSS 仅做外壳兼容。
- `web/app.js` 仅改视图入口与必要当前页标记：普通 `/` 默认 browse；`/?view=sources` 到原 sources；`/#/asset/{id}` 优先打开原详情，已有详情返回上下文优先恢复。无来源的明确添加入口链接管理视图，不把请求失败当作零来源。
- 五页共同外壳只把「照片 / 人物 / 地点」当主导航、「图库管理」当次级；**C 验收后移除侧栏重复“搜索”按钮／菜单项；A 期间保留旧可用入口**，不能删除 `/search` 深链或结果页。地图保留 `/map` 与地点互链。人物能力门控由各页原逻辑保持。
- 页头**最终**为全站唯一搜索输入；A 的过渡阶段只提供可正常进入并提交的旧搜索入口，**绝不放不可提交的页头假框**。C 紧接 A 负责原输入/submit 的完整迁移，A 不改搜索解析或复制监听。窄屏搜索须显式可访问、可聚焦，不能仅 hover 显示。人物/地点局部姓名/地名筛选必须有对象标签，不能与全局搜图混淆。
- 保留 DOM ID、原 script 次序和资源加载模式、原主内容 skip link、`hidden` 状态及事件绑定；地图容器布局变化后必要调用既有地图 resize，不能把地图裁成空白。
- 扩展已有颜色/间距/布局变量，尽量不新增公共 JS；保持系统暗色和键盘焦点。共享 CSS 不用无范围的 `header/main/section` 覆盖所有页。
- 不显示虚构总数、状态或无实现的设置按钮。资源版本同步更新；新本地静态资源须核对实际可被现有 package-data/web 路由提供，不改 Python 配置来迁就设计。
