# P4-02E — F1 语义积压领取有界化

本卡关闭 [P4-02B](P4-02B.md) §9 F1 与 [Sol 性能架构审查 §3](../reports/P4-02B-performance-architecture-review.md)、
[DS-H 审查 §4.4](../reports/P4-02B-dsh-engineering-review.md) 的专项：`jobs.claimable_candidates`
每次领取都物化并排序**整个可运行积压**（两侧 `USE TEMP B-TREE FOR ORDER BY`），于是「一次性投递
整个积压」的语义发布是二次成本：1 万 96.2 件/秒 → 10 万 47.3 件/秒 → 30 万截断样本 11.3 件/秒
（DS-H 独立复现：300 000 积压每次领取 117.95 ms ≈ 8.5 件/秒）。本卡只改**领取的取数路径**，
不改变「谁先被领取」。

推荐执行模型：**DS-H / DeepSeek V4.1 Flash / 高推理**（调度/状态面，按 V3.1 §2.4 走完整受影响面主审）。
Sol 聚焦终审**仅在被升级为公平/窗口契约变更时必选**。模型切换由用户在 Codex 中手动完成。

## 必须交付的实现事实

1. **一条领取 = 有界候选 + 精确裁决**：候选上界必须由**现有或新增索引**支撑，最终仍用原公式与
   `effective_priority DESC, created_at ASC, job_id ASC` 精确裁决。参考实现（主审已验证）：
   按 `(side, priority)` 类各取最旧 `limit` 行（同类内 `effective` 对 `created_at` 单调，故该类内
   全局序即 `created_at ASC, job_id ASC`），再整体按三键排序取前 `limit`；`UNION` 两侧的
   `QUEUED`/过期 `RUNNING` 与 `processor_id IN (...)` 过滤**逐字保留**。
2. **不改「谁先领取」**：对同一状态，优化前后的领取序列**逐项相同**（`job_id` 顺序与
   `effective_priority` 值都相同）。若实现中必须改变公平、饥饿上界或领取窗口 ⇒ **停止**，先做 ADR 冻结。
3. `0016` 为 additive migration：只新增索引（建议 `(state, priority, created_at, job_id)`，
   以实测 `EXPLAIN QUERY PLAN` 为准），不改表结构、不改数据；沿用 P4-00B 的迁移连续性/备份/
   回滚/旧构建拒绝新库证据口径。
4. 领取仍在写事务内（`Scheduler.claim_next` → `catalog.write()`），因此必须同时给出
   `write_hold_ms`/`lock_wait_ms` 的前后对照，证明写锁持有时间下降而不是把成本转移给别的阶段。

## 必须交付的验证证据（B + D）

1. **计划证据**：优化后领取主查询的 `EXPLAIN QUERY PLAN` **不得再出现** `USE TEMP B-TREE FOR ORDER BY`
   （两侧都要给），并给出新索引被使用的行。
2. **成本曲线**：复用 `tmp/p402b-dsh/f1_claim_probe.py`，给出 10 000 / 50 000 / 100 000 / 300 000
   积压下每次领取的中位/P95；验收门槛 = **不随积压显著增长**（主审实测参考值 0.92～1.02 ms，现况
   117.95 ms @30 万）。
3. **30 万一次性突发回归**：`--burst-sample` 覆盖全量、`--publish-wave` 不切波，`execute` 阶段吞吐
   必须回到与稳态波次同量级（现况 11.3 件/秒；波次 ≈79 件/秒；建议门槛 ≥ 70 件/秒），
   保留原始 JSON 与日志。
4. **等价性正式用例**（参数化，收编主审夹具）：混合优先级（含负数与高值）、同毫秒 `created_at`、
   跨多个 aging 窗口、`created_at` 在未来、`run_after` 在未来、过期/未过期租约、非目标 `processor_id`、
   `processor_ids=None` 与空集、`limit` ∈ {1,2,3,7,64,256}、aging 窗口 ∈ {1,60 000,86 400 000}、
   **重启后同状态同序列**。至少覆盖主审的 240 状态 × 6 × 3 组合规模（可参数化缩减样本但不得减少变量）。
5. **资格与租约边界**：不合格处理器仍走 `_block_unqualified`（不改判据）、过期租约 takeover
   仍计一次失败并不改变 `attempts` 语义、暂停态仍 `SCHEDULER_PAUSED`。
6. **变异测试**：去掉候选上界、去掉精确裁决、改变排序键各一次，必须让相应用例失败（证明用例非空转）。
