# P4-UI-TIMELINE-CLICK-PATH-FIX-A — 时间轴照片点击与文件路径显示修复

- 类型：小型 Bug 修复 / UI 优化
- 优先级：P1
- 状态：PLANNED
- 建议模型：GPT-6 Medium；出现跨组件事件冲突时用 High
- 测试：个人使用，最小定向测试
- 范围：浏览照片 → 时间轴模式

## 一、目标

修复两项已知问题：
1. 时间轴缩略图可以显示但点击无法打开现有照片详情。
2. 缩略图下方显示 `capture` 等内部时间标签；改为第一行真实文件名、第二行文件所在目录。

只修复现有功能，不重构 UI 2.0、不修改数据库 schema、不重新建库。

## 二、代码现状与根因

- `src/photo_search/web/photo-timeline.js` 的 `renderAsset()` 在 `adapter.renderAsset()` 存在时直接返回自定义卡片，跳过默认的 `adapter.onOpen` 点击绑定。
- `src/photo_search/web/app.js` 的 `timelineRenderAsset()` 构建了自定义 `button.photo-timeline__card`，但没有注册点击事件；首页挂载时间轴时已提供调用 `showDetail(asset_id)` 的 `onOpen`。
- `src/photo_search/api/timeline.py` 的 `timeline_page()` 当前返回 `asset_id`、`thumbnail_url`、`display_time`、`time_label` 等，但未直接返回文件名/路径。不能仅替换前端文案解决。

## 三、实施要求

### A. 点击照片修复

1. 点击首页时间轴自定义卡片，复用现有 `showDetail(asset_id)`，不得新建查看器。
2. 优先在首页自定义卡片/适配层做最小修复；若修改共享组件，先核查人物、地点等其他 `adapter.renderAsset` 使用方，避免重复绑定。
3. 单击只触发一次；不要让子控件事件意外打开详情。
4. 保持详情关闭、Esc、时间轴返回锚点、日期分组、滚动分页及懒加载原有行为。
5. 不改变资源身份、cursor、revision、排序或时间来源语义。

### B. 缩略图文件信息

固定两行：
- 第一行（主文字）：`IMG_20261014_102530.CR2`（真实文件名，保留扩展名、大小写）。
- 第二行（次要文字）：`D:\Photos\2026\旅行\深圳\`（真实文件所在目录，不重复文件名）。

规则：
1. 文件名和路径均来自现有资源/文件实例记录，不能根据 `asset_id` 或缩略图 URL 猜测。
2. 同一资产存在多个文件实例时，复用项目现有主实例/可用实例选择规则；不能任意选第一条。不同图库来源须显示正确目录。
3. 长文件名和长目录分别单行省略，固定两行布局，不撑大卡片或产生横向滚动条。
4. 鼠标悬停可查看包含文件名的完整绝对路径；触屏端通过现有照片详情获取完整信息，不依赖 hover。
5. 使用纯文本渲染，不插入 HTML。
6. 原文件丢失但库中仍保留可靠路径时允许展示记录路径；无目录时仅显示文件名；两者均不可得时显示“文件信息不可用”，不出现 `undefined`、`null` 或虚构路径。
7. 不再在缩略图下展示 `capture`、`added` 等内部字段；日期继续在年/月/日分组标题展示。
8. 文件路径仅作展示，点击和详情定位继续使用 `asset_id`。沿用本地相册既有数据访问边界，不扩大公共分享接口对绝对路径的暴露。
9. 浅色/暗色模式均需可读，保持现有网格尺寸与视觉风格。

### C. API 与性能

1. 核查现有资产文件实例、来源根目录、路径解析的既有逻辑；优先复用。
2. 如当前时间轴响应缺少路径，最小扩展 `GET /api/v1/timeline/assets` 的当前页 item，例如 `filename`、`directory_path`；具体字段命名遵循仓库约定。
3. 只为当前分页获取元数据；优先使用现有 SQL join 或单次批量查询。禁止每张照片单独请求详情 API，禁止 N+1 数据库查询。
4. 不扫描磁盘、不批量读取原图、不预加载整个图库路径、不改变分页大小。
5. 不修改数据库 schema 或新增索引；如果发现现有路径模型不足以可靠选取文件实例，先在报告中说明限制，不擅自扩大范围。
6. 目标是维持现有 30 万级图库按需分页的使用性能，不要求本卡进行大图库压测。

## 四、修改范围

优先：
- `src/photo_search/web/app.js`
- `src/photo_search/web/photo-timeline.js`（仅必要时）
- 时间轴相关样式文件（以仓库实际文件为准）
- `src/photo_search/api/timeline.py`
- 必要的既有路径查询辅助函数与定向测试

禁止扩展到人物识别、地点归类、搜索、图库扫描、撤销、原图解码、schema 或 UI 2.0 整体重构。
