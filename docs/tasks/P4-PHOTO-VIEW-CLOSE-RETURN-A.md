# P4-PHOTO-VIEW-CLOSE-RETURN-A — 照片查看关闭与人物页返回

日期：2026-10-11。状态：SCOPED PASS。基线：`dc952b2d49417e42c07bed466b75ed3b45a08cc7`。执行建议：GPT-5.6 Luna（C0；低风险前端修复，不需要独立审查或模型切换）。

## 1. 目标

修复统一照片查看流程中的两个体验问题：

1. 所有照片预览对话框均支持点击对话框外部遮罩关闭；点击对话框内部内容不关闭。
2. 从照片查看页点击人物头像进入 `/persons?person_id=...` 后，人物页主返回键显示并执行“返回查看照片”，优先返回浏览器上一页以恢复刚才的查看器；普通人物页入口继续显示“所有人物”。

覆盖共享 `AIPhotoInfo.open()` 查看器、搜索页查看器、人物相册查看器和地点查看器。地点查看器使用共享组件时应自动覆盖；保留地点旧式降级查看器的关闭行为。全屏哈希照片详情按已有返回浏览入口处理，不属于遮罩对话框。

## 3. 实现边界和不变量

- 允许修改共享照片信息/查看组件、搜索和人物查看脚本、地点预览降级、人物页返回按钮文案/绑定、静态资源版本，以及直接相关的合成 DOM 测试和本卡报告/状态。
- 不修改 API、数据库、人工人物归属、人物身份/撤销、照片数据、模型/索引或架构协议；不扫描或访问真实照片库。
- 遮罩命中仅在事件目标为 `<dialog>` 本身时关闭，内部面板、照片和操作控件不关闭；标准关闭按钮/Escape 继续有效；关闭事件仍释放 mount 与预览状态。
- 人物返回上下文由当前照片头像导航显式携带；人物页只在该上下文存在时改主返回按钮。浏览器历史返回优先，不破坏普通“所有人物”行为。搜索页继续保存并恢复原结果、滚动位置及当前照片。
- 若发现跨页上下文无法可靠恢复，先保留最小失败复现，再在当前范围内修复并验证；不得改人物数据协议。
