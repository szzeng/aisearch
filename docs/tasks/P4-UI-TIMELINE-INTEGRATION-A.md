# P4-UI-TIMELINE-INTEGRATION-A

## 目标

将 P4-UI-TIMELINE-CORE-A 已完成的 Timeline 能力接入实际用户照片浏览页面，使用户可以在相册中体验时间轴浏览。

当前状态：

- Timeline API 已完成
- Timeline 查询组件已完成
- Timeline 前端模块已存在

但是：

- 主照片页面仍使用旧照片列表
- 用户无法进入 Timeline 功能

本任务负责完成 UI 接入，不重新实现 Timeline 核心逻辑。

---

## 实现范围

### 1. 确认现有照片浏览入口

检查：

- 首页照片流
- 照片列表页
- 搜索结果照片页

确定 Timeline 主入口。

原则：

优先接入个人相册主浏览页面。

---

### 2. 接入 Timeline 组件

要求：

复用已有：

- photo-timeline.js
- Timeline API
- 已有 CSS/token

不要：

- 重写 Timeline 查询
- 新建另一套照片加载逻辑

---

### 3. 页面展示

基础体验：

照片按照时间分组展示：

- 年份
- 月份
- 日期
- 照片列表

支持：

- 首屏加载
- 滚动加载
- cursor 翻页
- 年/月定位

---

### 4. 与现有功能兼容

保持：

- 搜索结果照片浏览
- 人物照片浏览
- 地点照片浏览
- 合集照片浏览

不受影响。

---

### 5. 视觉要求

遵循已有 UI 体系：

- P4-UI-SHELL-A-F1
- UI visual tokens

保持：

- 字体
- 间距
- 暗色模式
- 卡片风格

一致。

---

## 不包含内容

本任务不做：

- revision 一致性修复
- 30万图库性能优化
- 新索引
- schema 修改
- 搜索优化

---

## 验收测试

### Test 1 页面入口

打开照片主页。

期待：

可以进入 Timeline 浏览。

---

### Test 2 时间分组

不同年份、月份照片正确显示时间分组。

---

### Test 3 滚动加载

大量照片场景：

- 按需加载
- 不一次加载全部照片

---

### Test 4 时间跳转

选择年份/月：

定位到对应照片。

---

### Test 5 暗色模式

Timeline 页面适配 dark mode。

---

## 测试范围

必须：

- 页面 smoke test
- 基础浏览测试

不要求：

- 全仓测试
- 30万压力测试
- 完整自动化浏览器回归

---

## 完成标准

PASS：

- 用户可以从正常入口进入 Timeline
- Timeline 数据来自 CORE-A
- 不存在第二套照片查询逻辑
- 基础浏览体验正常
- 样式符合当前 UI 体系
