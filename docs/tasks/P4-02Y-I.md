# P4-02Y-I — 来源建库与管理闭环

**状态：READY**  
**基线：master @ `b17ded6798e2432ab7b28d9e91712d7c27ba3bf5`**

## 目标

让每个“来源”的正常流程变成：

> **新增来源 → 开始建库 → 可以语义搜索 → 日常快速刷新**

并支持安全删除来源。

---

## 1. 开始建库

新增来源后显示：

> **未建库**  
> `[开始建库] [删除来源]`

点击「开始建库」后，复用现有 source-scoped refresh 自动完成：

```
扫描/确认文件
→ 搜索投影
→ Semantic 建库
→ 可以语义搜索
→ 后台继续 Face / OCR / GPS / Place / Thumbnail
```

新来源没有可复用绑定，首次 fast scan 会确认全部文件；**不要再额外先跑一次 full scan**。

现有 full scan 仅保留为“完整校验扫描”维护入口。

---

## 2. 首次大来源 backlog

首次来源可能有 20～30 万照片，不能只依赖单轮 `content_delta`。

建库模式必须根据持久状态持续分批追赶：

- Semantic；
- Face；
- OCR；
- 其它需要补齐的 enrichment。

要求：

- bounded batch；
- 可中断、可重启；
- 已完成资产不重复处理；
- 不因 delta/batch 上限永久漏处理；
- 复用现有 selector / jobs / processor，不另写第二套 pipeline。

---

## 3. 来源级进度

来源卡至少显示：

```
我的照片
D:\Photos

扫描：250,318 个文件
语义索引：183,500 / 231,420
状态：正在建立语义索引

人物：处理中
OCR：处理中
地点：完成
```

只要求 **Semantic 给出精确 completed / total**；Face/OCR/GPS/Place 可显示“处理中 / 完成 / 不可用”，避免为 UI 引入昂贵全量统计。

进度必须由持久状态推导，程序重启后仍能恢复。

### 语义状态

只有该来源当前可索引图片的 Semantic backlog 清零后显示：

> **✓ 可以语义搜索**

Face / OCR / GPS / Place 不阻塞该状态。

---

## 4. 日常操作

建库完成后来源卡主要操作：

> **快速刷新此来源**

继续复用 P4-02Y 的 skip-hash + delta 流程，只处理变化。

全局“刷新图库”继续刷新全部来源。

原“扫描”改名：

> **完整校验扫描**

作为次要/高级维护操作。

---

## 5. 删除来源

每个来源增加：

> **删除来源**

含义：

> 从 PhotoSearch 取消管理该文件夹。

要求：

- 删除来源登记及该来源相关 location / scan 状态；
- 来源立即从界面消失；
- 搜索/浏览不再把它作为有效来源；
- 同一 asset 若仍存在于其他来源，必须继续保留；
- **绝不删除、移动或修改任何原始照片。**

确认文案：

> 删除来源只会移除 PhotoSearch 中的记录，不会删除文件夹中的照片。

本卡不做 orphan asset/artifact/vector 的物理 GC。

---

## 6. 验收（只做小规模定向测试）

不重复 P4-02Y 已完成的容量/性能验证。本卡只做足以证明新增闭环正确的简单测试：

1. **首次建库**：20～50 张小来源，新增后只点一次「开始建库」，Semantic 完成后能搜索到其中照片；
2. **中断恢复**：建库中途停止/重启，再次继续时从持久 backlog 接着处理，不要求重新全算；
3. **日常刷新**：建库完成后新增 2～3 张照片，「快速刷新此来源」只处理变化；
4. **删除来源**：未建库和已建库来源均可删除，删除前后原始照片 **0 修改 / 0 删除**；
5. **共享 asset**：两个小来源包含相同照片，删除其中一个来源后，另一个来源仍可正常浏览/搜索该 asset。

同时做：

- 与本卡相关的定向 pytest；
- `ruff check`；
- `git diff --check`。

**本卡不要求：**

- 30 万真实规模测试；
- P95 / 性能基准；
- 浏览器自动化计时；
- GPU 性能测试；
- 全量 pytest；
- 重新证明 P4-02Y 已通过的容量结论。

大来源是否会因 delta/batch 上限永久漏处理，主要通过 selector/backlog 逻辑与小型边界定向测试证明，不重新制造 20～30 万夹具。

---

## 7. 不做

不做：

- 删除原照片；
- orphan artifact/vector GC；
- watcher / USN；
- ANN / FAISS / A3；
- 新 AI 算法；
- 模型升级；
- source remap；
- installer/MSI；
- P4-02Z RC。
