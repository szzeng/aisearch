## 目标

1. 建库只挑选**媒体层判定可解码的图像**作为目标；视频/音频/文档等「非图片资产」**不计为失败**，而是作为
   明确报告的「不在图文索引范围内」覆盖缺口（含数量与格式直方图）。
2. 建库进程按仓库唯一注册点 `photo_search.media.heif.ensure_heif_support()` 启用 HEIC/HEIF。
3. 提供 `--retry-failed`：把 FAILED 的逻辑 job 重置为 QUEUED（复用 face 的 `_rewind` 形状），用于修复后重跑。

## 边界

- 不改 schema/迁移/依赖；不改 `media/**`（只调用其既有公开函数：`plugin_format_decision`、`sniff_format`、
  `read_header`、`supported_input_formats`、`heif.ensure_heif_support`）；不改产物/outbox/generation/profile 语义。
- 已知未修：`indexing.cli reexecute` 仍走 adapter 的 path 直读（同样不注册 HEIF、不做方向归一），属另一张卡。
