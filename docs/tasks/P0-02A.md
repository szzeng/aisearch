## 不变量与行为

当前唯一应用接口 `GET /api/v1/health` 保持不变。SQLite 是未来业务状态的权威，FTS5 是文本检索能力；临时探针数据库不是产品 catalog，也不代表已实现 `search_documents`、迁移或 HTTP 搜索。

探针数据仅存于 pytest `tmp_path` 或脚本创建的临时目录；退出后不得在仓库、安装目录或用户数据目录残留数据库。所有命令使用 `uv run` 与 Python 3.12.10，不得使用 Python 3.14。结果必须来自实际 SQL，不得用固定成功 JSON、只检查编译选项或只验证 import。

在 `tools/benchmarks/` 实现可直接运行的探针，输出可机读且便于报告摘录的 Python 版本、`sqlite3.sqlite_version`、FTS5 创建结果与 SQL 查询结果。正常路径必须在一个新的落盘临时数据库中：

1. 建一个普通内容表和一个 FTS5 虚拟表（仅探针）。
2. 写入至少两条可区分记录，一条含中文词语，另一条含不同词语或英文。
3. 执行实际 FTS5 `MATCH`，断言只返回预期标识。
4. 关闭并重新打开同一数据库，重复查询并断言结果一致。

异常路径：FTS5 建表或查询失败时，探针以非零退出，输出 SQLite 版本、异常类型与消息，不得掩盖为 PASS。回归测试覆盖成功路径与关键结果断言。边界只覆盖一条中文精确查询；不要承诺中文分词、查询转义、外部内容表同步、更新删除触发器或 HTTP 搜索。
