# P2-01A — 地点事实、人工控制、数据包与搜索契约

执行模型：**C2 / GPT-5.6 Sol / high**。模型切换由用户在 Codex 中手动完成；本卡不启动其他
Agent、不切换客户端，也不得声称自动切换。

前置条件：P2-01 已 PASS，冻结 ADR-0003 及 p2-contracts.v1.json；P1-01～P1-06 均 PASS。
开始时以实际 Git、状态和 P2-01 报告复核，不从聊天历史假设。

本任务是地点实现前的 **C2 详细契约闭环**，只交付 ADR-0005、地点 JSON Schema、契约测试、
报告/状态和下一任务卡。不得实现地点表、GPS 解析、地名包导入、API、前端或调度器。

## 任务目标

把 ADR-0004 的规划决定和主架构 §4.5 转成可实施的无歧义协议，冻结：

1. GPS 原始事实、机器解析候选、人工有效归属三层对象及稳定 ID。
2. 人工指定、取消、恢复自动、批量操作、冲突、幂等、操作历史与补偿撤销。
3. 地名数据包 manifest、激活/回退、坐标基准、附近城市建议和缺包行为。
4. 增量 DDL/约束/迁移设计（只设计、不创建 migration）。
5. 纯筛选和组合搜索 API、错误码、版本/会话失效与权威补查。
6. 与 ADR-0003 的 non-model JobResult、CPU_PREFERRED、CatalogFilterRevision、SearchProfile 解耦。

首版产品范围固定为国家、城市、景点、自定义地点；支持 GPS 与无 GPS 手动归类。每资产最多一个
有效最具体地点，祖先查询自动展开。离线附近城市只给待确认建议，不把最近点当准确行政包含，也不
自动宣称景点命中。

## 必须交付

### 1. ADR-0005

新建 docs/decisions/ADR-0005-place-facts-assignment-and-search-contract.md，状态
ACCEPTED / FROZEN FOR P2 PLACE IMPLEMENTATION，至少冻结：

- Place：稳定 place_id、kind（country/city/attraction/custom）、规范名称、别名、父子层级、
  生命周期；同名允许，显示带祖先消歧；首版不做地点自动合并。
- GeoFact：asset/location/revision、GPS 原始值与规范化 WGS84、精度/海拔/方向等可选字段、
  来源、提取 processor、原始字段 checksum；无 GPS 是成功空结果；精确坐标不进入普通日志/URL/反馈。
- PlaceResolution：数据包版本、算法/config hash、候选、距离与置信依据、状态；最近城市只是建议，
  不能成为确定行政区；没有候选是成功。
- PlaceAssignment：每资产最多一个有效最具体地点；来源、人工锁、取消锁、恢复自动、有效/历史状态、
  revision 与 actor。手动归类不依赖 GPS。
- 人工事务：指定、重新指定、取消、恢复自动、地点改名/改父级、批量（上限 500）与补偿撤销；
  idempotency key、expected revision、原子性/逐项结果、冲突错误、操作日志与可撤销条件。
  自动处理永远不能覆盖人工指定或取消锁。
- DDL 设计：新增表/索引/唯一约束/外键/CHECK、软删除与审计、CatalogFilterRevision 单行版本；
  只设计下一增量 migration，不创建 migration、不改 0001_initial.sql，实际版本由 P2-03A 分配。
- 数据包 manifest：包 ID/version、来源/许可证、生成参数、内容 checksum、坐标基准、覆盖范围、
  语言/别名、构建器版本、兼容 schema、文件清单与大小；staged → validated → active → retained
  生命周期、原子激活、崩溃恢复、回退与引用保护。缺包/损坏包只阻塞解析，不影响人工地点。
- API：地点目录、asset 有效归属、确认建议、取消/恢复、批量/撤销、建议状态、覆盖率与搜索筛选；
  沿用 /api/v1、本机会话、CSRF、结构化错误和路径脱敏；冻结 revision、幂等和 409 冲突语义。
- 搜索：纯地点筛选读 SQLite；语义组合先约束候选并用最新 SQLite 复核；祖先/别名/改名命中；
  旧 catalog_filter_revision 会话明确过期。仅过滤旧结果不能补回新归类，必须补查/重搜或明确
  “索引更新中”。
- 版本触发矩阵：哪些动作递增 CatalogFilterRevision，哪些只更新机器候选；地点目录、数据包、
  profile、embedding space 各自独立，地点更新不重算 embedding。
- 正常/异常/边界矩阵：无 GPS、异常坐标、无候选、多候选/同名、取消锁、晚到机器结果、批量冲突、
  重复幂等、改名/改父级、引用中删除、缺包/坏包/切换/重启、并发整理、旧会话失效。
