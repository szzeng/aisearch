# P4-UI2-SHELL-STICKY-BROWSER-A — UI 2.0 吸顶外壳产品浏览器验收

> **状态**：READY / 等用户发起。前置 `P4-UI2-SHELL-STICKY-A` 已完成功能范围验证；本卡仅关闭真实产品浏览器证据。**建议执行模型**：GPT-6 Luna / medium（展示与交互验收）；由用户在 Codex 手动选择。
> **基线检查**：开始时读取 `AGENTS.md`、`docs/development-status.md` 与本卡，并核对 shell 代码 HEAD/工作树；沿用已实施代码，不因报告历史推测当前状态。
> **限制**：仅使用项目内合成数据与 Codex 内置浏览器；不得访问真实图库、真实地图 Key、模型/GPU或执行全仓/性能/打包测试。

## 目标

使用绑定 `127.0.0.1` 的真实产品服务和隔离合成数据，验证公共壳吸顶修复确实保留 window scroll、导航可达、搜索可用、地图布局和关键返回路径。启动不带 `--open-browser`；通过启动器获取一次性 session 链接，在同一内置浏览器仅打开一次，并先确认认证 API 可用。不得在报告中记录或暴露链接 credential。

## 路线

1. **首页长滚动 + 时间轴**：在可复用合成 fixture 中滚动至少 3 屏并触发至少两次续页；记录 `window.scrollY`、侧栏/页头可见状态、日期组头与页头间距、年月定位目标可见性。打开/关闭一个 viewer 后确认卡片位置与焦点仍合理。
2. **搜索页**：使用合成结果滚动并确认页头搜索保持可用；检查搜索页内容最大宽度/内边距、必要锚点定位不藏在页头下；若 fixture 支持合法范围，提交一次当前范围搜索并确认结果路由/返回可用，不修改搜索协议。
3. **地图**：检查桌面地图与照片列表独立滚动、地图移动和一个 hover 联动；在 850px 附近检查上下布局及照片可达。
4. **尺寸/无障碍**：覆盖 1440×900、1024×768、720px、640px 与一个短窗口；记录侧栏/紧凑导航入口、搜索输入与按钮、键盘焦点及横向溢出。仅当浏览器明确支持真实 zoom 控制时测试原生 200%；窄 CSS 视口不能代替。浅/暗主题和通知/模态遮挡只查有代表性的必要情况。
