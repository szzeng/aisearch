# P4-PERSON-COUNT-A — 人物相册显示人物数量

日期：2026-10-09。状态：**PASS / 定向 API 与 DOM 回归通过**。基线：`2ade131`（P4-PERSON-HIDE-UI-FIX-A）。执行记录见[报告](../reports/P4-PERSON-COUNT-A.md)。个人相册低风险只读统计展示。

## 目标

在个人相册三个列表状态显示符合当前筛选条件的完整人物数量：

- 「人物」：当前可见且已命名的人物数；
- 「整理一下」：当前可见、有效成员非空的未命名人物分组数。待整理人脸数量仍由收件箱原摘要表达，不与人物数混用；
- 「查看已忽略」：当前被忽略的活动人物数，包含已命名和未命名。

计数跟随名字搜索和可见性/类型条件，追加分页不重复累加，排序不影响总数。页面明确显示“共 N 人”。计数必须来自服务端完整筛选集合，不仅数已加载的40个卡片；不自动加载更多。

## 允许范围与不变量
