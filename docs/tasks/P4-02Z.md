## 6. 必测用户旅程

### A. 启动与重启

使用当前实际启动方式：

- 启动应用；
- 打开 Web UI；
- 正常显示来源、图库和搜索；
- 正常退出并重新启动一次；
- 重启后已有 catalog/index/profile 可直接继续使用。

不得要求用户重新建库。

**阻断：**
- 启动失败；
- 重启后库不可读；
- profile/index 丢失；
- 明显数据损坏。

---

### B. 来源与快速刷新

真实执行：

1. 查看已有来源；
2. 做一次 no-op “刷新图库”；
3. 在专用测试来源增加一小批真实图片；
4. 再执行快速刷新；
5. 观察 SCANNING → INDEXING → SEARCH_READY → ENRICHING/COMPLETE。

确认：

- no-op 不重新跑全库 AI；
- 新增图片只处理变化集；
- 到 SEARCH_READY 时新增图片已经可搜；
- face/OCR/GPS 等增强可以继续后台完成；
- UI 不要求用户手工再执行 semantic build。

这里不重复 P4-02Y 的 30 万性能实验，只验证真实产品体验和状态是否可信。

**阻断：**
- 新照片刷新后长期无法进入搜索；
- 每次刷新都重做大量已有 AI；
- no-op 明显退化成全库重建；
- 来源离线导致错误删除。

---

### C. 普通文字搜索

选择约 **10～15 条用户真实会输入的查询**，覆盖若干类型：

- 人物/关系；
- 场景/物体；
- 时间；
- 地点；
- 中文自然语言组合描述。

检查：

- 搜索能正常返回；
- 第一屏图片正常显示；
- 连续搜索不会经常报错；
- 结果整体有实际使用价值。

本卡不建立 Recall/nDCG 等正式质量指标，也不要求每条查询 top1 必须正确。

只有出现**系统性明显不可用**，例如大量普通查询都为空、完全不相关或持续错误，才算阻断。

---

### D. 浏览 / 详情 / 图片显示

实际浏览：

- 图库第一页；
- 滚动/翻页；
- 图片缩略图；
- 详情；
- preview；
- MISSING/offline 文件的诚实提示。

浏览器首屏历史上没有可靠自动 P95，所以本卡采用**人工体验判定**：

这只用于 PERSONAL TRIAL READY，不追认主架构“浏览器首屏 P95 ≤6 s”正式性能 PASS。

### G. 后台刷新同时搜索

执行一次真实小批量刷新/增强，同时继续做普通文字搜索。

只关注用户体验：

- 搜索可以继续使用；
- 不频繁出现合法请求 500/409；
- 可以暂时显示 LAGGING；
- 不出现几十秒级持续卡死。

本卡**不再以历史 D 的 8000 ms 与 8144.9 ms 差 144.9 ms 决定个人试用是否失败**。

### H. 来源临时离线

对一个可安全操作的测试来源：

- 临时断开/改名使来源不可访问；
- 打开图库/搜索；
- 恢复来源后再次刷新。

确认：

- 不把整源误判成删除；
- 已缓存缩略图/已有索引不会导致整个应用不可用；
- 恢复后可以继续刷新。

---

### I. 备份 / 恢复 smoke

不重跑 P4-05 全矩阵。

只用测试 data root 做一次最小流程：

1. 正常停机；
2. 创建一致性备份；
3. 恢复到一个新的空目录；
4. 用恢复目录启动；
5. 打开图库并执行一条普通搜索。

确认：

- 能启动；
- catalog 可读；
- 基本搜索可用。

不得用主个人图库做破坏性恢复覆盖测试。

## 7. 什么算 BLOCKER

只有下面这类问题阻止 RC：

- 原图被修改、删除或错误覆盖；
- catalog/index 明显损坏或重启后不可恢复；
- 快速刷新造成错误 asset 绑定或大面积错误 MISSING；
- 新增照片经过正常刷新仍长期不可搜索；
- 普通搜索频繁报错/崩溃；
- Web 基本浏览明显不可用；
- 备份恢复最小流程失败；
- 后台刷新导致应用长时间完全不可搜索；
- 用户的当前核心功能存在系统性错误。

发现 BLOCKER：

> 记录最小复现 → 立独立 bug 卡 → 本卡记 NOT READY。

不要在本卡直接修。

## 8. 什么不阻断个人试用

以下默认进入 **Known Limitations / 后置项**：

- 浏览器首屏没有自动 P95 测量框架；
- 后台正式性能 D 历史值略高于 8 s；
- 冷启动偶尔超过暖机门槛；
- 40 万以上容量尚未正式验证；
- GTX 1660 尚无当前正式认证；
- RAW 预览/完整格式覆盖未做；
- P4-03B 模型升级自动切换未实现；
- source remap 未产品化；
- watcher / USN Journal 未实现；
- A3 / ANN / FAISS 未启用；
- 正式安装包/多机器发行能力未完成；
- 没有正式 Recall/nDCG 标注质量集；
- 个别 UI 文案、布局、状态展示不够漂亮；
- face/OCR/GPS 等增强比 SEARCH_READY 更晚完成。

除非真实使用证明其中某项已经成为核心不可用问题，否则不因此继续当前开发阶段。

## 11. RC1 之后的工作方式

进入 PERSONAL TRIAL READY 后：

**不再主动继续性能/架构优化。**

以后只按真实使用问题立卡，例如：

- “这批新照片刷新后搜不到”；
- “某个 HEIC 无法显示”；
- “某次来源断开后恢复异常”；
- “某类查询明显搜不准”；
- “刷新实际用了 20 分钟，影响使用”。

一个问题一张卡。

以下继续 DEFERRED，除非真实使用触发：

- A3；
- ANN / FAISS；
- watcher / USN Journal；
- P4-03B 模型升级；
- 40 万以上优化；
- 正式发行/安装器；
- 多机型认证。

本卡的最终目标不是“证明系统完美”，而是：

> **确认当前版本已经足够安全、稳定、方便地开始长期个人使用。**
