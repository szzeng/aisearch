## 搜索单入口与目录范围返回补充（2026-10-13）

从唯一页头搜索进入结果、预览照片、点击人物/地点相册，再返回时，要恢复搜索 q/条件 chips/候选范围/滚动和原始人物/地点**局部目录筛选**；不能恢复“顶部+结果正文”的两个搜索框，也不能因为返回误再提交一次 NLP/向量搜索。人物/地点内部的拍摄时间轴缺日期照片照常可预览，预览中日期来源显示为未知或待就绪，不生成虚假“查看拍摄同一天”按钮。切人物/地点时不能继承上个 scope 的年月过滤。只改显示/恢复连接，写协议与导航上限不变。

## 「搜索此相册」与预览返回验收补充（2026-10-13）

用户从张三/家庭合集/深圳相册点快捷搜索，结果页以**单一页头输入框 + 可见 scope chip**显示固定范围；打开结果照片、再跳至某个人物/地点、使用浏览器返回时仍能还原原搜索词、范围、排序、当前结果页/候选 session、滚动；进一步返回原相册时还原其时间依据、年/月筛选、滚动锚点和按钮焦点。不能触发二次编码器查询或将 scope 静默扩大到全库。清除 scope chip 后才使用全局结果和新游标；来源相册身份/版本失效时清晰提示重新进入。与已有 F 卡的预览状态修复共用检查，不重写导航/会话。
