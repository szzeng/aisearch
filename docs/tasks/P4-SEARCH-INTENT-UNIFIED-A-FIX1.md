# P4-SEARCH-INTENT-UNIFIED-A-FIX1 — 统一搜索候选去重与范围消歧修复

**状态：修复完成 / 定向验证通过 / 真实图库现场记录未检查**
**关联任务：** [P4-SEARCH-INTENT-UNIFIED-A](P4-SEARCH-INTENT-UNIFIED-A.md)

## 问题

用户反馈统一搜索后出现重复或不可区分的同名选项。回溯代码发现两类触发条件：

1. 同一人物的正式名和同值别名分别被识别成同一原文区间的候选，随后被重叠检查误判为选择歧义。
2. 不同真实身份匹配同一查询时，确实需要用户选择；统一搜索改用范围选择 UI 后移除了既有的人物 ID、地点上级/来源等区分信息，导致按钮不可区分，且单类地点/人物歧义会显示“不同范围”的错误提示。

## 范围与验收

- 候选按意图类型、真实对象身份和原文区间去重；不同人物 ID 的同名候选保留为真实歧义。
- 重复的人物、地点、来源或合集选项显示稳定的身份区别；地点优先显示上级与来源，仍重名时显示 key。
- 提示按候选类型区分人物/地点/来源单类歧义与跨范围歧义。
- 合成测试覆盖正式名与同值别名产生的重复候选、不同人物经共享别名产生的真实冲突、同名香港地点的父级消歧、同名图库来源 ID 消歧，以及前端标题和选项。
- 不读取真实 `PhotoSearchData` 或现有服务，不扩展人物数据治理或重命名流程。
