# P4-SEARCH-PREVIEW-A — 搜索结果连续查看照片

日期：2026-10-04。状态：IMPLEMENTED / 人物关联定向验证通过；搜索查看器原有跨页验收仍待做。

## 目标

搜索结果缩略图可点击查看大图；查看器提供上一张、下一张和当前位置，顺序与当前搜索结果一致，交互模仿人物照片查看器。

## 范围与不变量

- 修改搜索页和人物相册页 HTML/CSS/JS；复用只读 `GET /api/v1/assets/{asset_id}` 读取单张照片元数据，不新增 API、不改搜索排序/会话/筛选契约，不读取整库。
- 查看器展示结果排名、资产编号、尺寸、格式、文件大小、规范化拍摄/文件时间及相机信息；可用字段缺失时不编造值，详情读取失败时仍保留排名和资产编号。
- 元数据展示只选取明确信息字段，不展示 `locations`/相对路径、内部哈希或原始 EXIF。
- 查看器人物栏只列出当前照片中已有有效人物归属的人；按 canonical `person_id` 去重。优先展示人物封面脸作为头像，无封面时用当前照片中的对应人脸作回退；未归属/待确认的人脸不猜测身份。
- 点击人物头像打开 `/persons?person_id={id}`，人物页按服务端 canonical 人物详情直接进入现有分页相册；点返回回到人物列表并清除定向参数。访问相册仍经现有受会话保护 API。
- 导航只使用已加载的 `state.search.hits`；到当前结果末尾且仍有游标时，下一张复用现有搜索 session/cursor 请求一页。
- 首张上一张禁用；末尾且无下一页时下一张禁用；分页失败保留当前照片并可重试。
- 关闭查看器或开始新搜索/重置时，迟到的分页/图片响应不得切换新列表。
- 原有“查看详情”链接、搜索结果顺序与分页条件保持不变。

## 验收

- 小型合成 UI 验证：人物头像去重/封面缺失回退/无归属人/跳转；人物定向打开相册及返回；人物查看、封面、整理回归。
- 搜索查看器点击/跨页/错误重试/关闭竞态、元数据错误状态仍未动态验收。
- Node 语法检查与 `git diff --check`。
- 不访问真实图库、不启动可能写入 PhotoSearchData 的服务、不运行全量或性能测试。

## 实施状态

搜索缩略图改为可聚焦按钮；新增大图对话框、导航、单张照片信息和已归属人物头像。人物头像可直达其分页相册，人物页支持定向打开。新人物关联场景及人物页回归已通过小型合成 UI/JUnit 验证；原搜索查看器跨页交互尚未验收。实现说明见[报告](../reports/P4-SEARCH-PREVIEW-A-implementation.md)。
