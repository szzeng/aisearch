# P4-SEARCH-PREVIEW-A — 搜索结果连续查看照片

日期：2026-10-04。状态：IMPLEMENTED / 静态检查通过 / 合成交互验收待做。

## 目标

搜索结果缩略图可点击查看大图；查看器提供上一张、下一张和当前位置，顺序与当前搜索结果一致，交互模仿人物照片查看器。

## 范围与不变量

- 只修改搜索页 HTML/CSS/JS；复用只读 `GET /api/v1/assets/{asset_id}` 读取单张照片元数据，不新增 API、不改搜索排序/会话/筛选契约，不读取整库。
- 查看器展示结果排名、资产编号、尺寸、格式、文件大小、规范化拍摄/文件时间及相机信息；可用字段缺失时不编造值，详情读取失败时仍保留排名和资产编号。
- 元数据展示只选取明确信息字段，不展示 `locations`/相对路径、内部哈希或原始 EXIF。
- 导航只使用已加载的 `state.search.hits`；到当前结果末尾且仍有游标时，下一张复用现有搜索 session/cursor 请求一页。
- 首张上一张禁用；末尾且无下一页时下一张禁用；分页失败保留当前照片并可重试。
- 关闭查看器或开始新搜索/重置时，迟到的分页/图片响应不得切换新列表。
- 原有“查看详情”链接、搜索结果顺序与分页条件保持不变。

## 验收

- 小型合成 UI 验证：点击缩略图打开大图；元数据字段白名单/缺失/错误处理；上一张/下一张及当前位置正确；首尾状态正确；跨页保持同一 session/cursor；分页失败重试；关闭和新搜索竞态；现有详情链接仍有效。
- Node 语法检查与 `git diff --check`。
- 不访问真实图库、不启动可能写入 PhotoSearchData 的服务、不运行全量或性能测试。

搜索缩略图改为可聚焦按钮；新增大图对话框、导航和单张照片信息。实现复用当前搜索分页，不预取结果；元数据仅从详情接口白名单字段展示。静态检查已完成；小型合成 UI 验收尚未执行，故不标 PASS。实现说明见[报告](../reports/P4-SEARCH-PREVIEW-A-implementation.md)。
